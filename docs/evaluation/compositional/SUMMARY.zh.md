# 词库已有词的找回与构式组合：实测结论

共享 planner 已接入真实 BGE 和静态精确检索。它把原表达改写为谓词、论元、语义中心与构式要求；实际检索后再选择词形、安排角色和形态。原始查询结果始终保留。

完整实验覆盖 60 例、11 类转换和 15 个留出表达。89 个可核查成分目标有词典见证 ID 或语保调查点／序号依据；另有 3 个目标未核定，不计入召回分母。召回率按每例的已核查成分目标宏平均，属于检索指标，不是译文准确率。

## 还没有解决的部分

- 分解 BGE 剩余的已核查目标漏检见逐例 missed_existing_components；未核定的“审判”不被误记为数值上的检索失败，也不被当作已有译法。
- 施事与受事不仅在角色图中分开：施事指人的草案使用 ma，受事草案使用带施事的关系从句和显式受事中心词。缺少“审判”词形时，完整表达仍属于未完成的研究草案。
- “收入减少”等表达可能找回相关词，却仍需更好的结果谓词选择；词形、词干变化、近期完成与结果状态、数量词及跨调查点搭配仍有检查项。
- 现有数据没有系统的词源标注，无法把所有罗马字形式统计为本族词。报告分别记录有据词形使用、汉字插入和未完成词汇槽位；不把零汉字插入冒充完整翻译。
- 普通翻译按 skill 给出完整调号拼音和 IPA，统一附一条质量说明。逐词来源、候选淘汰理由和未完成槽位留在这份明确请求的审计报告中。
