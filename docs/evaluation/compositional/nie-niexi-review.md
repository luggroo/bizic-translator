# nie／niexi 与三项候选更正

- 开瓶器：不应把 `nie + 东西` 设为唯一默认实现。语境明确时，`tīkū tóng niexi`（开瓶子的）是应考虑的生产性拟式。Feng 第10页例27对独立指称和显式中心词作了直接对照；[skill 核读笔记](../../../skills/translate-tujia/references/nie-niexi.md)列出限制和原文页码。
- yǎn’gócě：词条 w2526，见证 stedt-rn-453495，来源 Brassett 06 / STEDT 原定位1.1，原词形 yan³guo²ce³，原英语 rainwater。它表示雨水，不能自动等同于降雨事件。先前“遮雨的东西”草案还拼入仙仁点60756的 thaŋ33（挡），不能仅凭组件命中认为译法合格。
- 审判：c42、c43 的 `[predicate]` 是未填的“审判”，并没有隐藏在 ma 或 nie 里面。两例只能测试角色差异，不能算已经给出审判相关译文。语义框架通过并不表示句子译完。
