# 真实词典语义检索评测

BGE 已成功加载并编码完整公开字典，建立持久索引，返回带义项、见证和出处的候选。此报告比较字面与向量检索，并分别测试句子和语法构式检索；没有金标准或母语者评分，不报告准确率。

## 数据与模型

- 公开来源固定于 bizic-dictionary 提交 `bc3aadfbe877d83b723f6ad37dfc1d0df0b48198`。
- 原始字典含 9,297 个合并词条、19,577 条见证；适配器保留各见证的中英义项、词性、方言、出处及关联记音，不把父条目的聚合释义套给所有来源。
- 模型：`BAAI/bge-base-zh-v1.5`；revision：`f03589ceff5aac7111bd60cfc7d497ca17ecac65`。
- 权重 SHA-256：`731cf5d88ed555a21ff2f2d9fa4db43b10489173ddd9178db3eecfd7a2bae044`；PyTorch 2.7.1+cpu，Transformers 4.51.3；CPU、4 线程、768 维。
- CLS 向量与 L2 归一化；查询前缀：`为这个句子生成表示以用于检索相关文章：`。长记录使用重叠窗口，未用模拟向量、同义词表或关键词回退替代语义检索。
- 当前索引记录 23694 条，唯一编码文本 7088 条；不同来源或调查点可以共享同一汉译向量，但仍是独立证据。
- 类型计数：`{"lexical_sense": 11598, "survey_lexeme": 10765, "survey_sentence": 399, "text_block": 123, "grammar_section": 234, "corpus_passage": 575}`。
