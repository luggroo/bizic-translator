# 土家语体貌与情态：按汉语语义检索 / Aspect & modality

**读本文件前先在 [grammar-index.md](grammar-index.md) 找原文触发词。** 这不是一张让模型自由拼接后缀的表；在龙山默认先用 Brassett 2006，2004 为辅助。例句统一展示 **调号拼音（首列）＋IPA**，不把叶氏拼音当展示形式。B06 = Brassett、Brassett & Lu（2006）；[补充] = 网站参考语法中的未刊口语“吃中饭”，**不等于 Brassett 龙山原例**。每条标了来源以免跨地点拼接。

<a id="prospective"></a>
## 1. 快要、要、马上、就要、该……了

**先判断是将然意图、临近起点、快达到终点、许可、义务还是进入新情况。** 汉语“要”不是一枚土家语副词：北部资料有未然 /i/（会引起词干韵部变化）、起始 /xu/、完结 /tɕi/、情态等不同形式。

| 汉义 | 调号拼音 | IPA | 来源 | 选择条件 |
| --- | --- | --- | --- | --- |
| 将／去吃中饭 | ōnggǎ gái | /ɔ̃⁵⁵ka²¹ kai²⁴/ | [补充] | 未然／预期，不必马上发生 |
| 正要吃中饭 | ōnggǎ gáhǔ | /ɔ̃⁵⁵ka²¹ ka²⁴xu²¹/ | [补充] | 马上要开始，不是马上吃完 |
| 要去吃中饭 | ōnggǎ gáihǔ | /ɔ̃⁵⁵ka²¹ kai²⁴xu²¹/ | [补充] | 未然＋起始 |
| 马上吃中饭 | ōnggǎ gáhǔlǎ | /ɔ̃⁵⁵ka²¹ ka²⁴xu²¹la²¹/ | [补充] | 起始的更迫近读法 |
| 需要吃中饭 | ōnggǎ gádō | /ɔ̃⁵⁵ka²¹ ka²⁴tuɔ⁵⁵/ | [补充] | 必要，不是一般将来 |
| 可以吃中饭了 | ōnggǎ gádōhǔ | /ɔ̃⁵⁵ka²¹ ka²⁴tuɔ⁵⁵xu²¹/ | [补充] | 现在满足许可/条件 |
| 该吃中饭了 | ōnggǎ gǎtīhǔ | /ɔ̃⁵⁵ka²¹ ka²¹tʰi⁵⁵xu²¹/ | [补充] | 义务/时机到来 |
| 快吃完中饭了 | ōnggǎ gájīhǔ | /ɔ̃⁵⁵ka²¹ ka²⁴tɕi⁵⁵xu²¹/ | [补充] | 临近终点 COMPL+INCH |
| 天气冷透了 | tiānqǐ sàjíliāo | /tʰian⁵⁵tɕʰi²¹ sa⁵³tɕi³⁵liau⁵⁵/ | 陈康 2006:109 | 性质词达到终点 |

- Brassett 2006:123–124、137–139 证明：/i/ 并非单纯将来时，既可计划，也可反事实；/xu/ 涉及事态临近或进入新阶段。不能一见“快要”就任意加一个 /xu/ 到任意词后。
- **独立核读点**：陈康（2006:105–109）记录“冷”从“将冷／快冷／刚开始冷／冷透／冷过”等多种范畴，其实词的形态和声调并不一定与 Brassett 龙山方言同形。上表未把不同来源的词尾硬拼成一套范式。

## 2. 还、仍、正在、还没、尚未（作用域至关重要）

“还”有至少四种易混读法：**仍在做、尚未做、尚未做完、仍不必做**。不同的 V＋体／否定／情态组合承载这种含义；不要只把 `ɲie` 当成逐词的“还”。

| 汉义 | 调号拼音 | IPA | 来源 | 与其他“还”的区别 |
| --- | --- | --- | --- | --- |
| 正在吃中饭 | ōnggǎ gálā | /ɔ̃⁵⁵ka²¹ ka²⁴la⁵⁵/ | [补充] | PROG 行动进行 |
| 吃着中饭 | ōnggǎ gábō | /ɔ̃⁵⁵ka²¹ ka²⁴pɔ⁵⁵/ | [补充] | STAT 动作/状态保持 |
| 还在吃中饭 | ōnggǎ gálāniē | /ɔ̃⁵⁵ka²¹ ka²⁴la⁵⁵ɲie⁵⁵/ | [补充] | PROG+CONT |
| 在吃中饭了 | ōnggǎ gálāhǔ | /ɔ̃⁵⁵ka²¹ ka²⁴la⁵⁵xu²¹/ | [补充] | PROG+INCH，新情况 |
| 天气还在变冷 | tiānqǐ sàlāniē | /tʰian⁵⁵tɕʰi²¹ sa⁵³la⁵⁵ɲie⁵⁵/ | 陈康 2006:108 | 性质词+进行+仍在 |
| 他们还不必睡觉 | gè niébǒtādǒnié | /kɤ⁵¹ ȵiɛ²⁴pɔ²¹tʰa⁵⁵tuɔ²¹ȵiɛ²⁴/ | B06:140 ex.220 | 还作用于整段“不必睡” |
| 你还不必把水全放完 | ní cě hájítādǒnié | /ȵi²⁴ tsʰɤ²¹ xa²⁴tɕi²⁴tʰa⁵⁵tuɔ²¹ȵiɛ²⁴/ | B06:140 ex.218 | “还”作用于完结＋不必 |
| 并不是你不能住在这里 | ní gě ǒngbǒtātīdá | /ȵi²⁴ kɤ²¹ ɔŋ²¹pɔ²¹tʰa⁵⁵tʰi⁵⁵ta²⁴/ | B06:140 ex.219 | 否定整个复合能力情态 |

**“还没吃”与“还没吃完”**：田志慧 p.526 另外记录 /ka³⁵ ta⁵⁵ ɲie⁵⁵/、/ka³⁵ tɕi⁵⁵ ta⁵⁵ ɲie⁵⁵/。这两条在当前参考语法中只有 IPA，没有独立的调号拼音逐词对照，**暂不算双转写已核例句**；应在 [notation-audit.md](notation-audit.md) 完成来源校验后升级。不因为这两个结构也带 /ɲie/ 就认定和 Brassett 文献的 `nief` 具有完全相同的搭配范围。

<a id="completion"></a>
## 3. 已经、了、过、做完、结果仍在、刚刚、不再

先区分 **PFV 整体事件**、**COMPL 达到目标**、**PRF 与现在有关**、**EXP 过往经历**、**STAT 保持状态**；汉语“已经、过、了”本身不足以选形式。

| 汉义 | 调号拼音 | IPA | 来源 | 区别 |
| --- | --- | --- | --- | --- |
| 吃过中饭了（事件事实） | ōnggǎ gáliē | /ɔ̃⁵⁵ka²¹ ka²⁴lie⁵⁵/ | [补充] | PFV：事件作为整体 |
| 吃过中饭了（当前结果） | ōnggǎ gábōlū | /ɔ̃⁵⁵ka²¹ ka²⁴pɔ⁵⁵lu⁵⁵/ | [补充] | PRF：当前仍有关 |
| 吃完中饭了 | ōnggǎ gájībōlū | /ɔ̃⁵⁵ka²¹ ka²⁴tɕi⁵⁵pɔ⁵⁵lu⁵⁵/ | [补充] | COMPL+PRF：达到终点 |
| 吃过中饭 | ōnggǎ gábōlā | /ɔ̃⁵⁵ka²¹ ka²⁴pɔ⁵⁵la⁵⁵/ | [补充] | EXP：既往经历 |
| 天气冷透了 | tiānqǐ sàjíliāo | /tʰian⁵⁵tɕʰi²¹ sa⁵³tɕi³⁵liau⁵⁵/ | 陈康 2006:109 | 性质词：完结＋完成 |
| 天气冷过 | tiānqǐ sàbōlā | /tʰian⁵⁵tɕʰi²¹ sa⁵³po⁵⁵la⁵⁵/ | 陈康 2006:109 | 性质词：经历体 |
| 坐下并坐着 | ǒng bǒ | /ɔ̃²¹ pɔ²¹/ | B06:90 ex.110 | 状态继续；不是进行 |
| 把书打开并保持打开 | cīpū tóng bǒ | /tsʰɿ⁵⁵pʰu⁵⁵ tʰɔ̃²⁴ pɔ²¹/ | B06:90 ex.111 | 结果状态维持 |

- Brassett 2006:136, exx.194–195 对照“吃过”（陈述事实）与“现在已经吃过”（当前情况相关），通常分别用 PFV 和合音式 /liau/。不能把所有“了”自动补成同一个后缀。
- **尚未核定的调值**：参考语法里的 `ongxgar gafliao` 这一组补充口语明确没有给 `liao` 声调；标准拼音／IPA 双转写暂不把它标成已核，不能根据常见 /liau⁵⁵/ 直接改写为确定的调号。
- “刚刚”在鲁曼等（2021:431–432）的 /po xi/ 与 /liao/ 对照中，涉及**事件已结束 vs 结束后的状态仍在**。没有理由把 /po xi/ 直接推广为一般“刚才”的后缀。
- **“不再／已经不能”** 不等于一次普通否定。Brassett 2006:120、131–137 的 /tʰa tʰi/＋当前关联等组合形成特定的状态变化读法；必须按整句判断情态及否定范围。

## 4. “会、能、可以”先分：能力、熟练、力气、时间、许可

| 汉语意义 | 土家语中需区分的完整构式 | 原文证据 |
| --- | --- | --- |
| 能读 vs 不能读 | 一般能力 /tɤ⁵⁵ ɕi²¹/；复合否定 /tʰa⁵⁵ tʰi⁵⁵/ | B06:127–128（这两个是情态组成，不是完整引句；查整句时务必返回调号拼音＋IPA 对齐形式） |
| 会犁地／做得熟练 | 熟练 /ɣɤ⁵⁵/，不同于客观可行 | B06:127–128 |
| 提得动／织不动 | 力量许可 /tsʰɤ⁵⁵/；体力不足 /xɨ⁵⁵ tsʰɤ⁵⁵/ | B06:127–129 |
| 没空吃／来不及 | 时间条件 /pie⁵⁵/；否定 /tʰa⁵⁵ pie⁵⁵/ | B06:128–129 |
| 已经不能走了 | /tʰa⁵⁵ tʰiu⁵⁵/（脚痛的场景） | B06:131–132 |

这些是**分析性的 IPA 构式标记**，并非例句。具体引用未收入双拼音对照表时，不要冒充已检查；如要把词形用作新句，核实同来源的词干、后置位置与负义组合。一般能力 ≠ 习得技能 ≠ 体力 ≠ 时间充裕 ≠ 许可。

## 5. 想、愿意、必须、可以、该、不必、不许、恐怕

| 汉语意义 | 分义和语法选择 | 原文证据 |
| --- | --- | --- |
| 想／不想 | “想”作为谓词后情态，否定“想”和否定实际动作不能合并 | B06:129–130 |
| 愿意／不愿意 | /tsʰɤ/ 可表示意愿，也有同形体力形式，否定搭配不同 | B06:129–130 |
| 必须／得 | /tuɔ/ 可表示义务必要；不要与位置不同的 /tuɔ/ 结果含义混同 | B06:129–130 |
| 不必／不许 | 语气、重音、场景可区分，不总是两枚独立否定标记 | B06:129–130 |
| 先／优先 | /pʰie⁵⁵/ 可为谓词后先行义；不是万能“然后” | B06:129–130 |
| 恐怕／担心 | /ɕi²¹ ke⁵⁵/：不利情况的担忧；非中性“可能” | 田志慧:611 |

### Brassett 谓词后次序（十位置约束）

| 顺位 | 作用 |
| --- | --- |
| 1 | 程度、达到终点 |
| 2 | 完结或状态；部分未然异位 |
| 3 | 未完成／完整体 |
| 4 | 趋向 |
| 5 | 未然（常规位置，可合音） |
| 6 | 一组情态：意愿、体力否定、先后 |
| 7 | 意愿／判断否定 |
| 8 | 另一组情态：一般能力、许可、必要、熟练、时间 |
| 9 | 事实否定 |
| 10 | 仍然、当前相关、新情况 |

**组合边界：** 按 Brassett 2006:139–140, Table 7.1，同位成分通常互斥，第6/8两组情态不能随意共现，第7/9两组否定通常互斥；第8位已有负义的情态可再受第9位否定（见上表“并不是你不能住这里”）。其他北部材料中有 /tɕi+pɔ/ 等不同搭配，不得自动推给龙山。词干变化、缩合和声调须按来源配对核查。

## 7. 本文件怎么帮翻译更快

1. 先定位 “将然/快要”→§1、“还”→§2、“已经/过”→§3、“能/会”→§4、“想/必须”→§5；**只读相关段落**。
2. 在本来源内优先复用完整例句，检查谓词性质、语义作用域、词干变体及后置成分次序；**不是拿 IPA 后缀自由拼接**。
3. 发现新构式或转写冲突时，才去指定数据库查证；执行时间受控，不能改用外网搜索。
4. 翻译必须完整，按 **调号拼音＋IPA** 交付，叶氏拼音仅按用户要求显示。来源缺调或无法转换的地方，逐段标 `⟦待核调号/IPA⟧`，不能装作已验证。
