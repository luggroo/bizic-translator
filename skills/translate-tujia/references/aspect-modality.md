# 体貌、体态与情态构式速查（北部为主；附南部对照）

## 使用原则 / How to use

这是一份给 translate-tujia 用的**已查证构式索引**，按汉语/英语的语义而非表面的副词顺序组织。遇到“还、已经、快要、马上、刚、先、能、会、该、必须、想、不再”等信号词，**先查本文件的歧义和原例**，再判断是否需要新检索。

- **先确定意义和论元、事件阶段、范围，再选词干形态及谓词后成分。** 汉语“要”可表达将然、紧迫、义务、愿望、命令；“还”可表示动作持续、未完成、某种能力仍存在、或“尚不必”，不是同一个可随意插入的词。
- 这里主要收录**北部不同调查点**的例子，不能把 Brassett（龙山及相关调查）、陈康、田志慧（隆头）和未刊补充口语材料的词形/调值随意拼接为同一方言。**Brassett 2006 仍为龙山优先证据**；2004 为辅助，只有在具体缺口出现时才扩展至其他北部来源。
- 本文件是检索缓存，而非证明整套范畴能产或组合都可行。例句分为 **[B06]** Brassett、Brassett & Lu（2006）文献原例或其完整片段；**[C06]** 陈康（2006）；**[T]** 田志慧；**[Y95]** 叶德书（1995）所录；**[YY]** 杨溢；**[L21]** 鲁曼等（2021）；**[补充]** 未刊补充口语材料；**[教学]** 依文献成分组成而非原始引句。只有确实存在的完整原例可以标 **文献原例**；表内独立词形和词组一律不能冒称原书整句。
- 下文 IPA 和调值依记录来源，叶式拼音与 IPA 并列但**没有进行跨来源统一**；/i/ 常与词根合音，不可自行在任何词尾机械添加 i。页面中的“体态”在此包括未然、体貌与情态，**不等于语态**。
- Source pointers: [Bizic Academy reference grammar §4.1](https://github.com/luggroo/bizic-dictionary/blob/main/docs/reference-grammar.md), especially §4.4, §4.6, §4.7, §4.10; Brassett 2006, §7.2–7.3, pp. 109–140. 本索引只固化已有资料，不需要每次翻译重新读完文献。

## A. 从汉语的副词、助动词找到正确构式（优先查此表）

| 汉语可能表达 | 先区分什么 | 北部候选结构（不是一对一译词） | 对照例 / 资料 |
| --- | --- | --- | --- |
| **将、要、打算、会发生** | 将然/非现实、计划、假设，未必临近 | 词干＋未然 /i/（可变韵） | /ka²⁴/ → /kai²⁴/ “将吃”；/sa⁵³/ → /sai⁵³/ “将冷”；Brassett 2006:16；[C06] |
| **快要、正要** | 动作将开始 vs 快完成 | V＋/xu/（进入新阶段），或 V＋/i/＋/xu/（将然＋起始） | /sa⁵³ xu²¹/ “快要冷了” [C06:105–109]；/kai²⁴ xu²¹/ “要去吃” [补充] |
| **马上、就要** | 临近开始 vs 已有计划 | V＋/xu la/ 或相应合音；某些性质词有未然＋起始的组合 | /ka²⁴ xu²¹ la²¹/ “马上吃中饭” [补充]；/sai⁵³ xu²¹ la²¹/ “就要冷了” [C06] |
| **该……了** | 时机到了、有义务 vs 获得许可 | 义务情态＋起始体；不可当单纯将然 | /ka²¹ tʰi⁵⁵ xu²¹/ “该吃中饭了” [补充] |
| **可以……了** | 许可以及条件现在满足，不是“必须” | 许可/情态＋/xu/ | /ka²⁴ tuɔ⁵⁵ xu²¹/ “可以吃中饭了” [补充]；同形 /tuɔ/ 在不同位置有不同作用 |
| **正在** | 动作进行 vs 状态保持 | V＋/la/（进行） | /pu³⁵li⁵⁵ mian⁵⁵tɕie⁵⁵la⁵⁵/ “果子正在变红” [Y95:85]；/ka²⁴ la⁵⁵/ “正在吃” [补充] |
| **……着、保持着** | 状态保持 vs 进行动作 | V＋/po/～/pɔ/（状态） | “把书打开并保持打开”：cixpux tongf bor [B06:90, ex. 111] |
| **还在……、仍然……** | 某动作或性质变化仍在进行 | V＋/la/＋/ɲie/（延续） | tianxqir savlaxniex “天气还在变冷” [C06:108]；gaflaxniex “还在吃中饭” [补充] |
| **还没……、尚未……** | 事件没有发生 vs 完结终点尚未达到 | V＋否定＋/ɲie/；V＋完结＋否定＋/ɲie/ | /ka³⁵ ta⁵⁵ ɲie⁵⁵/ “还没吃”；/ka³⁵ tɕi⁵⁵ ta⁵⁵ ɲie⁵⁵/ “还没吃完” [T:526] |
| **还不必……** | 义务现在尚未成立（不是还不能） | V＋状态＋不必＋/ɲie/；前述否定和状态受固定顺序制约 | gev niefbortaxdornief “他们还不必睡觉” [B06:140, ex. 220] |
| **还做得起、仍有能力** | 能力仍保持；不等于动作仍在进行 | 能力＋/ɲie/ | /zi⁵⁵ tsʰai⁵⁵ ɲie²¹/ “还做得起” [T:623–626] |
| **开始、已经开始……** | 进入新状态，和动作完成不同 | 进行＋起始；性质词亦可 | /sa⁵³ la⁵⁵ xu²¹/ “已经开始冷了” [C06:105–109]；gaflaxhur “在吃中饭了” [补充] |
| **快……完、差不多完成** | 接近终点，非单纯快开始 | V＋/tɕi/＋/xu/ | /ka²⁴ tɕi⁵⁵ xu²¹/ “快吃完中饭了” [补充] |
| **……了、已经……** | 事件发生、完成到终点，还是跟现在相关？ | /lie⁵⁵/（有界整体）；/tɕi/（完结）；/liau/（当前相关）；/tɕi liau/（完成且达到终点） | /ga² lie¹/ vs /ga² liao¹/ [B06:136, exx. 194–195]；savjifliaox “冷透了” [C06:109] |
| **曾经……、……过** | 经历曾发生 vs 现在结果仍在 | V＋/po la/（经验）；另有来源特定变体 | tianxqir savboxlax “天气冷过” [C06:109]；/ka³⁵ po⁵⁵ la⁵⁵/ “吃过” [YY:35] |
| **从来没……过** | 否定经历，不等于“尚未完成” | V＋/po ta/（已记录的经历否定） | /ka³⁵ po⁵⁵ ta⁵⁵/ “没吃过” [YY:35]；不自动加“从来”语义 |
| **不……了、不再……** | 事实否定、意愿否定，还是状态不再成立 | 来源相应的 /tʰau/ 或 /tau/；与普通 /ta/、/tʰa/ 对照 | /ɣɨ³⁵ ta³⁵/ “没去”，/ɣɨ³⁵ tʰa⁵⁵/ “不去”，/ɣɨ³⁵ tʰau⁵⁵/ “不去了” [YY:34] |
| **已经不能……了** | 能力从先前可行变成不可行 | /tʰa⁵⁵ tʰiu⁵⁵/；不能当普通否定＋将来 | /ɣɨ²⁴ tʰa⁵⁵ tʰiu⁵⁵/ “已经不能走了”，脚疼的语境 [B06:131–132] |
| **先……** | 动作先后次序、优先，未必需要再用汉语副词 | V＋/pʰie⁵⁵/，必要时有额外限制 | /xu²¹ pʰie⁵⁵/ “先喝” [B06:129–130] |
| **刚刚……** | 发生时间刚近 vs 结果状态延续 | 注意 /po xi/ 与 /liao/ 的对照；**不能把 po xi 定义成一般“刚刚”后缀** | 鲁曼等 [L21:431–432, ex. 45] “我刚刚吃饭”对比：前者突出饭后仍保持的状态，后者突出吃饭事件结束 |
| **恐怕、怕会……** | 负面事件的担忧，不是简单概率“可能” | 谓词（或相关结构）＋/ɕi ke/ | /sa⁵⁵ ɕi²¹ ke⁵⁵/ “恐怕会冷着”；/lo²¹ ɕi²¹ ke⁵⁵/ “恐怕会挨骂” [T:611] |
| **又、再、仍、还**（其他义） | 重复事件／追加对象／“还给”／让步等不同语义 | **没有充分证据时不自动用 /ɲie/**；先查该义的独立词或重叠构式 | “还在”“还没”“还不必”仅授权上述语义与结构，**不授权**“再做一次”“又来了”等读法 |

## B. 三组最易误译的最小对照

### B1. 将要、临近、开始、许可、义务（以“吃中饭”为中心）

以下部分“吃中饭”的声调与汉译来自**未刊补充口语语料**，不是 Brassett 原文逐句引例。应在龙山翻译中先看 Brassett 对 IRR、INCH、MOD 的限制（pp. 123–140），再考虑这些北部词形；**不应把它们直接推广成龙山范式**。

| 形式（按原资料） | 意思 | 语义区别 |
| --- | --- | --- |
| ongxgar gaif | 将/去吃中饭 | 未然 /i/，不保证事情迫在眉睫 |
| ongxgar gafhur | 正要吃中饭 | 起始，动作临近 |
| ongxgar gaifhur | 要去吃中饭 | 未然＋起始，行动计划＋临近 |
| ongxgar gafhurlar | 马上吃中饭 | 比单独起始更紧迫 |
| ongxgar gaflax | 正在吃中饭 | 过程正在发生 |
| ongxgar gaflaxhur | 在吃中饭了 | 进行成为新情况 |
| ongxgar gafjixhur | 快吃完中饭了 | 临近**终点**，而非临近起点 |
| ongxgar gafdox | 要/需要吃中饭 | 必要情态，不等于计划 |
| ongxgar gafdoxhur | 可以吃中饭了 | 条件/许可现在成立 |
| ongxgar gartixhur | 该吃中饭了 | 义务/时机现在成立 |

注意：接同一汉语“了”，选择不同组合会改变是**动作开始、许可生效、义务到来**还是**完成达到终点**。

Brassett 原例也说明 /i/ 不等于将来时：/ŋa²⁴ xuɔ²¹ ti²⁴ i/ “我会拿来”、/kuɔ²⁴ je²¹ ka²⁴ i tsʰa²⁴/ “他想吃点东西”、/ɲi²⁴ je²¹ ka²⁴ i tɤ⁵⁵ ɕi²¹/ “你可以吃点东西”（[B06:123–128]）。/i/ 还见于未实现的计划和反事实条件，[B06:123–124, exx. 118–119]。

### B2. “还”看 scope，不能逐词翻译

| 形式与来源 | 汉义 | 范围 |
| --- | --- | --- |
| tianxqir savlaxniex [C06:108] | 天气还在变冷 | 对**持续进行**的状态变化取范围 |
| /ka³⁵ ta⁵⁵ ɲie⁵⁵/ [T:526] | 还没吃 | 尚无所述事件 |
| /ka³⁵ tɕi⁵⁵ ta⁵⁵ ɲie⁵⁵/ [T:526] | 还没吃完 | 有可能已开始，未达到终点 |
| gev niefbortaxdornief [B06:140, ex. 220] | 他们还不必睡觉 | **不必睡**的判断在当前仍成立 |
| nif cer hafjiftaxdornief [B06:140, ex. 218] | 你还不必把水全放完 | “还”修饰**不必做完**这一复杂判断 |
| /zi⁵⁵ tsʰai⁵⁵ ɲie²¹/ [T:623–626] | 还做得起 | 延续的是**有能力**，并非动作正在进行 |

不要把汉语“还”直接插到词首，也不要因上面都见 ɲie 就默认各种极性、时貌组合可以互换。**Brassett 的第 10 位置用于当前关联/还/新情况，而不同来源中 ɲie 的标调与功能还需保留。**

### B3. “已经”“了”“过”：事件、终点、经历、当前结果

| 形式 | 对照汉义 | 判断问题 |
| --- | --- | --- |
| ga² lie¹ [B06:136, ex. 194] | 吃过了，作为事实陈述 | 事情发生了？（PFV） |
| ga² liao¹ [B06:136, ex. 195] | 已经吃过，现在与招待/饥饿情况相关 | 以前的事**现在有关**？（PRF） |
| ongxgar gafjixboxlux [补充] | 吃完中饭了 | **整顿饭/目标完全结束**？ |
| ongxgar gafboxlax [补充] | 吃过中饭 | 以前有过经历？ |
| tianxqir savjifliaox [C06:109] | 天气冷透了 | 性质变化**达到某程度的终点**？ |
| tianxqir savboxlax [C06:109] | 天气冷过 | 曾经有过这个状态？ |

其他合音：Brassett 将 /lie/＋/ku/→/liau/、/ta/＋/ku/→/tau/、/tʰa/＋/ku/→/tʰau/、/tʰa tʰi/＋/ku/→/tʰa tʰiu/ 分析为和当前相关的组合（[B06:120, 131–132, 135–137]）。这是该文献的**分析和受限的已记录形式**，不意味着模型可以对任意后缀字符串自行拼合。进行体 /la/ 也可描述过去事件中的过程或习惯行为，不能当作必然“现在时”。

## D. 成分次序和组合限制（套用前必检查）

Brassett 2006:139–140, §7.3, Table 7.1 给出**十个相对位置**（不是说每个谓词都必须十项全有）：

| 位置 | 典型功能 / 标记 |
| --- | --- |
| 1 | 达到程度 /sɨ/、/tuɔ/ |
| 2 | 完结 /tɕi/；状态 /pɔ/；未然位置变体 /i/ |
| 3 | 未完成 /la/；完整体 /lie/ |
| 4 | 趋向 /ɕie/、/lie/、/lu/、/ti/ |
| 5 | 未然 /i/（通常位置；可能合音） |
| 6 | 一组情态：/tsʰɤ/、/xɨ tsʰɤ/、/tsʰa/、/pʰie/ |
| 7 | 意愿/判断否定 /tʰa/ |
| 8 | 另一组情态：一般能力、许可、必要、熟练、时间条件等 |
| 9 | 事实否定 /ta/ |
| 10 | 仍然/当前相关/新情况：/ɲie/、/ku/、/xu/ |

- **同一位置**的成分一般不可随意同现；第 6、8 两组情态在 Brassett 的分析中互斥；第 7、9 位置一般互斥，**但第 8 位置的负义复合情态可再受第 9 位置事实否定**：nif ger ongrbortaxtixdaf “并不是你不能住在这里” [B06:140, ex. 219]，不是简单“不能住”。
- /lie⁵⁵/ 完整体和 /lie²¹/ 趋向要分开。/pɔ²¹/ 状态与其他位置的 /pɔ⁵⁵/ 关系/向格形式不能靠同形等同。/tuɔ/ 既见于结果程度也见于必要，依附位置和构式才可判定。
- **不同来源的组合范围不同**：Brassett 把第 2 位 /tɕi/ 与 /pɔ/ 作为互斥，同页另一组“吃中饭”补充资料存在 /tɕi+pɔ/ 组合。不能据此宣称所有龙山谓词都允许两者连用。
- **“还”作用于整个复杂谓词**：gev niefbortaxdornief “他们还不必睡觉” [B06:140, ex. 220]；nif cer hafjiftaxdornief “你还不必把水全部放完” [B06:140, ex. 218]。不能只看“还”就直接添加一个粒子。
- 本表不是排列组合生成器：先找到**语义、谓词类、否定范围**吻合的整体原例；相近生产性规则才可用于新句，遇到冲突优先报告为拟译中局部待核，不必中断全文翻译。

## E. 南部土家语：不能把北部后缀照搬

以下来自 **《泸溪土家语》（李敬忠，2000）** 与**向亮《南部土家语研究》（2017）**，都是语法文献中的例子：

| 汉语意义 | 原文记录 IPA | 来源 |
| --- | --- | --- |

## F. 每次翻译时的调用流程（用以减少重复查证）

1. **标记原文语义触发词**：如“快要、马上、还在、尚未、已经、又、先、能、会、该、必须、不愿”，拆出真实的事件时间、持续/结果、情态种类、逻辑极性。
2. **查 A 表及 B/C 的真实对照**：找最接近语义的现成例句，同时核对方言及证据类型。允许采用已列举的生产性结构，不必因同一个经典例句每次重新搜索数据库。
3. **套用次序约束 D**：标明谓词类（动态/状态/性质）、词根变化、各位置、是否合音、前后成分共现限制，以及否定/当前关联作用域。
4. **南部单独用 E**；不确定是不是同一地方的记录，就不直接套北部词尾。
5. 只有在**新词根、新搭配、新语义、冲突或证据缺口**时，才使用指定本地/静态数据库做有界的语料查证。禁止额外网络搜索；语义 embedding 没跑不要冒充已跑。
6. 将**已证实**、**有据类推**、**未刊补充**、**待核拟译**在解释中区分；不要因为不确定而停下翻译。对长文按主 Skill 要求分阶段交付真实进展。
