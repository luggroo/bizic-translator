# 事件、连动与从句链接 / Event relations

适用北部／龙山翻译。**先判断 A、B 的语义关系，再选构式**，不要先替换汉语“然后、着、当、用”。所有引例都按 **调号拼音 → IPA** 显示；叶氏原记法不作展示。完整原例和页码见 [Bizic 参考语法](https://github.com/luggroo/bizic-dictionary/blob/main/docs/reference-grammar.md) §§6.4–6.5、7.3。B06 = Brassett 等（2006）。

<a id="time"></a>
## 1. 最快判断：五种事件关系

| 意义 | 构式选择 | 适用限制 |
| --- | --- | --- |
| **A 已经做完，接着 B** | A＋完成体 /liɛ⁵⁵/（传统检索别名 `liex`）＋B | 先动作作为有界事件；**不等于过去时**，未来操作步骤也可用 |
| **做 A 的方式做 B** | [A 方式短语]＋/mɔ²¹/（别名 `mor`）＋B | 可以连数量短语、动作方式；不是简单“和” |
| **维持着 A 的状态再做 B** | A＋/pɔ²¹/＋/mɔ²¹/（别名 `bor mor`）＋B | /pɔ/ 的状态范围和主体要保留；不是所有“正在”都用此构式 |
| **只保持一个状态** | 谓词＋/pɔ²¹/（别名 `bor`） | 保持状态的要求可以与祈使语气共存；不必须有 B |
| **B 发生时以 A 为时间背景** | A＋/tsu²⁴/（别名 `zuf`），B | “当……时”，并不自动说明 A 比 B 先完成 |

**注意同形：** 完整体 /liɛ⁵⁵/（`liex`）和趋向 /liɛ²¹/（`lier`）不是同一标记。/pɔ²¹/ 持续态与 /pɔ⁵⁵/ 方向或关系形式不能靠旧拼法猜。查拼音的音节与声调，再看 IPA 与句法位置。

## 3. 补充的重要事件构式（由 IPA 反推的拼音，仍待独立复核）

以下三句见现有参考语法 §6.4（Brassett 2006:152–154），但原始缓存只给**IPA**，没有可独立核对的整句调号拼音。表中拼音依据网站音节规则重构，明确标记为 **「待独立核」**：它们有助于选择语法，**不能拿重构拼音再去证明来源 IPA 正确**。

| 汉义 | 调号拼音（拟转写，待独立核） | IPA（原记） | 出处 |
| --- | --- | --- | --- |
| 他笑着走了 | gó niè bǒ mǒ zǎo | /kuɔ²⁴ ɲie⁵¹ pɔ²¹ mɔ²¹ tsau²¹/ | B06:152–154, ex.32 |
| 我坐着吃饭 | ngá ǒng bǒ mǒ zǐ gá | /ŋa²⁴ ɔ̃²¹ pɔ²¹ mɔ²¹ tsɿ²¹ ka²⁴/ | B06:152–154, ex.31 |
| 打好糍粑后，分着吃 | bā bā bú liē, jiū dà pǐ mǒ gá | /pa⁵⁵ pa⁵⁵ pu²⁴ lie⁵⁵, tɕiu⁵⁵ ta⁵¹ pʰi²¹ mɔ²¹ ka²⁴/ | B06:152–154, ex.25 |

对应的区分是：（1）**笑＋状态＋方式＋走**，不是笑完才走；（2）**坐姿持续时吃饭**；（3）**打糍粑已完成**，后面的分配是吃的方式。这是对完整构式的消歧，不是三个可以无条件互换的通用连词。

- **使用工具**：名词（工具）放在“用”之前，最后是切、拿、写等主动作。不要把汉语“用刀切菜”的语序直接照搬。
- **单纯叙事**：上下文清楚时可以并列小句或省略已知主语；不必每次加传统别名 `liex`、`mor`。

## 4. 何时才继续搜索

仅在没有相同**事件关系、词类及参加者**的现成例子时，检索同一方言的完整小句，优先 Brassett（2006）→2004，再扩展其他北部调查点。动作完成／正在／“还”等体貌/情态问题另查 [aspect-modality.md](aspect-modality.md)，否定和名词短语另查 [clause-patterns.md](clause-patterns.md)。不要访问外部网页，也不为再找到同一句例句重复请求。
