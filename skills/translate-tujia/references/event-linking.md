# 事件、连动与从句链接 / Event relations

适用北部／龙山翻译。先判断 A、B 的语义关系，再选构式。新译文的格式见[输出规范](output.md)；原例保留来源记音。参考语法：[连接动作：方式与先后](https://tujia.biz/#grammar/north/106?grammarAnchor=north-serial-verbs)、[连接小句：时间、目的与条件](https://tujia.biz/#grammar/north/106?grammarAnchor=north-time-condition)。完整原例和页码见 [Bizic 参考语法](https://github.com/luggroo/bizic-dictionary/blob/main/docs/reference-grammar.md) §§6.4–6.5、7.3。B06 = Brassett 等（2006）。

含移动事件时，先按[趋向构式](direction-suffixes.md)选择表达，再用本页组织事件关系。

## 1. 最快判断：五种事件关系

记录各事件、参与者及背景、先后、方式、目的、原因或条件关系，并保留它们是否属于同一次活动。时间背景把主事件定位在某次活动或时段内；先后关系表达事件的次序。先行事件完成后留下的状态可能延续到后一事件，构式选择还须结合体貌、焦点与完整例句。

条件表达保留条件事件、结果事件及必要或充分关系。以某事件为必要条件，与排除其他施事、强调某位参与者分别表达；施事焦点本身不承担事件条件关系。

按[完整谓语流程](predicate-economy.md)选择相同事件关系的近例；维持状态作方式时采用相应状态／方式构式。

| 意义 | 构式选择 | 适用限制 |
| --- | --- | --- |
| **A 已经做完，接着 B** | A＋完成体 /liɛ⁵⁵/（传统检索别名 `liex`）＋B | 先动作作为有界事件；未来操作步骤也可用 |
| **做 A 的方式做 B** | [A 方式短语]＋/mɔ²¹/（别名 `mor`）＋B | 可以连数量短语、动作方式，表达方式关系 |
| **维持着 A 的状态再做 B** | A＋/pɔ²¹/＋/mɔ²¹/（别名 `bor mor`）＋B | /pɔ/ 的状态范围和主体要保留；按整句区分状态与进行 |
| **只保持一个状态** | 谓词＋/pɔ²¹/（别名 `bor`） | 保持状态的要求可以与祈使语气共存；也可独立成句 |
| **B 发生时以 A 为时间背景** | A＋/tsu²⁴/（别名 `zuf`），B | “当……时”，以 A 为时间背景 |

**同形与变调：** `lie` 的连动、完整体和离心功能按结构及来源gloss识别，55／21表面调不能独自定功能。`bor` 等成分也结合功能与前调，见[助词变调](aspect-modality.md#particle-sandhi)。

- **使用工具**：名词（工具）放在“用”之前，最后是切、拿、写等主动作。按工具—用—动作组织。

## 动作与位移：独立先后与弱义趋向

徐世璇、鲁美艳（2014）《土家语动词体标记-i的来源和语法化过程》，《民族语文》2014(6):18—26，[原文](https://drive.google.com/file/d/1vdZZ4NEnPi_0D5c6eg-GllEazPIPbgEt/view)。本篇未注明具体采录点；下例保留其IPA和调值。

| 表达条件 | 本篇构式 | 作用范围 |
| --- | --- | --- |
| GO是独立表意重心，先移动再做TASK | GO＋连动lie＋TASK | 两个动作分别有参与者和阶段；本篇否定连动例分别给两动词加否定。 |
| TASK为重心，施事到异地实施TASK | TASK＋GO；或空间V-i | GO是从属趋向；词序本身不表示先做完TASK再离开。 |
| 单一空间V-i带否定或体 | [V-i]＋否定／体 | V-i作为一个句法单位接受修饰；各标记按其来源的形式和范围组合。 |

| 汉义（原译） | 原文IPA | 定位 |
| --- | --- | --- |
| 大家都去山上挖地。 | `xu³⁵ni⁵⁵ kʰã²¹kʰu⁵⁵ ɣi³⁵ lie⁵⁵ li⁵³ ka⁵³` | 2014:19，例2②；强义先后 |
| 他要挖地去了。 | `ko³⁵ li⁵³ ka⁵³ ɣi³⁵ xu⁵⁵` | 2014:20，例4；弱义TASK＋GO |
| 他们昨天没去背柴。 | `kɤ³⁵ pʰũ²¹ni²¹ kʰa²¹ woɪ⁵³ ta³⁵` | 2014:21，例7②；空间V-i的过去否定 |

空间V-i涉及施事位移；受事是否移动及其源点、终点由主谓词和上下文确定。独立的移动、活动完成和返回分别落实。位移V-i可用于过去及其他时体；具体后接成分的顺序、否定和音形采用相应来源规则。记音和[-i的多种用法](aspect-modality.md#i-functions)分层记录。

## 4. 所以、然后、不然：北部连接词

表达因果、先后和否定条件时，按下列北部Brassett词项与分句构式选形；南部表达使用相应南部证据。

| 汉义 | 调号拼音（词条派生） | IPA（词条派生转写） | 检索别名 | 词条与来源 |
| --- | --- | --- | --- | --- |
| 所以、因此 | āimǒ | /ai⁵⁵mɔ²¹/ | `aixmor` | [w174](https://luggroo.github.io/bizic-dictionary/?lang=zh&id=w174#words)，Brassett 2004，原记 ai1mo3；Brassett 2006 §7.6 的 STEDT 见证 rn 455293 |
| 然后、接着 | āiliē | /ai⁵⁵liɛ⁵⁵/ | `aixliex` | [w172](https://luggroo.github.io/bizic-dictionary/?lang=zh&id=w172#words)，Brassett 2004，原记 ai1lie1；Brassett 2006 §7.6 的 STEDT 见证 rn 455291；完整用例见上表 B06:69, ex.86 |
| 否则、不然 | āitā | /ai⁵⁵tʰa⁵⁵/ | `aixtax` | [w175](https://luggroo.github.io/bizic-dictionary/?lang=zh&id=w175#words)，Brassett 2004，原记 ai1ta1；Brassett 2006 §7.6 的 STEDT 见证 rn 455295，释 otherwise, if not |

- **因为A，所以B**：先表达原因A，再以 **āimǒ** 承接结果B；上下文明确时也可直接连接原因和结果分句。
- **A，然后 B**：用 **āiliē** 表先后；若需明确 A 已完成，再按事件性质选择完成体 **liē**。完成体与连接词各有作用。
- **A，不然B**：表示“否则／若不如此”时选 **āitā**；另提建议的“不然……”按建议的语义和相应例句选形。

证据快照：`luggroo/bizic-dictionary` commit `3c28f08ab78fc54a719f7f0d660e0fb5717f6fff`，`site/dictionary.json.gz`。调号拼音由该版转换器从有对应见证的叶式词形生成（w7742、w6250、w7161）；IPA 是词条所列 Brassett 派生转写，未独立核听。上方完整例句保留其 /lie⁵⁵/ 原记，不将两种转写冒充同一原始记音。Brassett 2006 的词项定位来自 STEDT 转录，未逐页重核原书。
