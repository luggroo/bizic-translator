# 读土家语原文：词界、记音与句义

先保留原文，再找词界和记音近似的候选。把候选放回句子判断；记录采用了哪一处差异，不直接改动原记音。以下检索变体来自不同资料记音及本轮用例，不是各方言中一律成立的音变规则。

## 找不到连写形式时，先恢复词界

空格不保证对应词典词条。一个连写片段可能含几个词、词干与词缀，也可能是固定复合词；分别保留这些分析。有整词候选时，仍检查能否拆为短语，尤其是无调输入。

同时检索整词、多个独立词和词干加词缀的分析。分词后逐一核对词义、词性及它们在句中的关系；不要只按字面最相近或第一个释义选词。

## 逐层放宽记音

| 差异 | 检索办法 |
| --- | --- |
| hx 声母有无 | 保留 hx 与零声母两个候选；同时处理零声母 i/u 的 y/w 拼写。IPA 路线比较 /ɣ/ 与零声母。 |
| 舌根音后的 i / ei | 在 g、k、ng、h、hx 后尝试 i / ei；IPA 按相应舌根音比较。其他声母不因此通配。 |
| 高调与降调 | 高调、降调作近似候选，原来的调值及来源各自保留。 |
| 词缀的声调 | 已认出可能的词缀时，检索这个词缀的异调。整词词尾不能仅因位置靠后就自动认作词缀。 |
| 21 55 / 35 55 | 比较两个音节的整体调型，先检查前一音节差别。 |
| 35 35 / 35 55 | 比较两个音节的整体调型，检查后一音节差别。 |

区分来源专属的转写规则与真实读音差异。调号拼音经过对应来源的转换后，可按其调类比较；原 IPA 不补调、不改调。未列出的声调区别（如 31 / 33）继续保留。

## 本地检索

从仓库根目录运行。程序只用 Python 标准库，加载一次本地词典，并为多个查询复用索引；它不运行 embedding。

```sh
python scripts/reverse-lookup.py --query soxtir --notation ye
python scripts/reverse-lookup.py --query sōtǐ --notation accent
python scripts/reverse-lookup.py --query heircef --notation ye --affix-tone
python scripts/reverse-lookup.py --query 'so⁵⁵thi²¹' --notation ipa
```

`whole` 保留整词候选，`segmentations` 保留分词候选；每个候选有原词形、词义、来源、定位、采用的差异及编辑代价。代价只计算记音差异，不表示语义相似度或译文正确率。相同词条的重复见证集中到 `alternative_witnesses`，避免挤掉别的词义。

`--affix-tone` 只对词典中明确带词缀标记的记录放宽声调。`heircef` 可据此召回 -hīcē“不起／不能完成”，接着应检查它与前面的动词、体貌成分怎样组合；“用尽”与“用不完”的极性不能由单个未解尾词略去。

每段至多八个音节、四个词典成分；每个片段最多检查 64 种音段候选，默认返回 30 条候选。一次可用重复的 `--query` 传入至多 32 个片段。未支持的记音会报错或计入 `unsupported_forms`；改用已明确识别的拼音或 IPA，不把解析失败报告成词不存在。

无代码工具时，按相同步骤人工拆分和改查已发布词典页面；不声称执行了这个程序。静态分片不含全部语保词汇，必要时继续查已有的调查点材料，并分开记录来源版本。

## 从词义回到句子

保留否定、完成、能力、程度和方式等语法成分。比如 `xir` 可以对应草，也能召回词缀 -xǐ“很、非常”；需要检查前后谓词及程度构式，不能只因“草”是一个真实词条就译成“草长大”。

确定词界后，先给接近原句结构的汉语释义，再组织通顺译文。原有参考译文用于事后对照；独立测试时不提前提供它。
