# Blocker → next action / 禁止式规则的操作替代路线

This is an **execution router**, not a list of disclaimers. Apply it to the main Skill, the synonym-lite subskill and the grammar references. Whenever a rule says *do not*, *never*, *cannot*, *avoid*, *only when* or equivalent, select the matching **next action** immediately. Treat the prohibited step as a cue to move forward, not as a reason to stop translating.

**Fast path for ordinary translation:** source semantics → Brassett (2006 → 2004) → real BGE or synonym-lite → original witness → relevant grammar-index topic → draft a complete clause. Reuse source records and query results; pursue a second route only if a key semantic role remains uncovered.

| Blocker / tempting shortcut | Next action (the alternative) | Stop / output condition |
| --- | --- | --- |
| Web/general GitHub search is excluded during translation | Query the designated local `tujia-lex` / public Bizic data checkout. In text-only tools use `lexicon/manifest.json` plus its FNV-selected shard and `tujia-synonym-lite`. Consult user-supplied files directly if authorized. | If outside evidence is absent, translate using available witnesses and a transparent localized gap; keep the outside-source question for a separate research task. |
| Missing model/index or uncertain execution capability | Apply [environment preflight](runtime-lifecycle.md) before installation/build. Reuse existing compatible assets first; provision missing ones only with confirmed capability and durable storage. Otherwise directly run synonym-lite exact lookup. | A complete failed setup is not a prerequisite for **Skill-based**. Offline with cached assets can still use BGE. |
| BGE/model process exists, but the current query, index digest or source completeness cannot be verified | Inspect `manifest.json`, source revision and model metadata. Validate the current query; rebuild only a proven incompatible index after the preflight/storage gate. | Label **Embedding** only after actual inference. On a confirmed blocker, keep reusable assets, record the cause and use static lookup. |
| Assets would be stored only in tmp or a workspace with unknown lifetime | Locate a documented durable volume, reusable environment snapshot or authorized artifact/restore destination; record its lifecycle and paths in `.local/tujia-runtime.json`. Ask for a storage choice only if the provider/user must enable it. | Existing usable assets may serve this query; otherwise use static lookup while arranging persistence. Temporary paths serve scratch/tests only, not sole long-term storage. |
| A Chinese compound / abstract / literary term has zero exact matches | Apply `semantic-decomposition.md`: original expression → everyday paraphrase → main action/property/head → participants/result → grammatical construction; query each high-value candidate with a bounded batch. | Use a productive native paraphrase; if a necessary lexical slot is still missing, insert the smallest Chinese content word and continue the clause. |
| A nearest vector neighbor is merely related, opposite, more general or a different species/kinship term | Record its relation (synonym, paraphrase, hypernym, component, antonym, unrelated), test the full meaning and role, and rerank verified source witnesses. | Select an equivalent construction; preserve a specific feature as an extra modifier if only a broad term is available. |
| A form is found only in a different variety or lacks recorded locality | Compare Brassett 2006, then 2004, then explicitly localized Longshan sources and related Northern witnesses. Record each source's scope; use the best-supported variant as a **provisional cross-variety adaptation** if necessary. | Keep the requested Longshan variety clear; identify borrowed spans in the single final quality note or detailed audit if requested. |
| Brassett 2004 and 2006 differ, or source glosses/OCR/alignment conflict | Inspect original attestation, source-specific notation and adjacent sentence/parallel text; prefer 2006 when supported. Where local originals are available, check their scanned pages or audio. | If irreconcilable, use the best-supported full form, preserve the conflicting witness in the internal trace and state the exact contested part once. |
| A story has only a cultural summary or a related legend | Search the **available structured corpus and source metadata** by title/variant/subject, inspect continuous blocks or original passage, and extract only verified phrases for matching events and participants. | Draft the user's specified story with its own names/causes/ending rather than replacing it with the variant. |
| A full sentence is unattested | Find a close attested construction with the same **event roles**, change one licensed component at a time, and apply `clause-patterns.md` / `event-linking.md`. | Produce a complete **拟译**, documenting the particular adaptation in audit mode. |
| A Chinese adverb/function word lacks an obvious Tujia word | Classify **aspect, modality, direction, comparison, negation, focus or clause relation** first; route via `grammar-index.md` to `aspect-modality.md`, `event-linking.md` or `clause-patterns.md`. | Express it with the appropriate predicate shape/stem/particle or a linked clause, preserving scope. |
| `liex` / `mor` / `bor` appear interchangeable, or event linkage is unclear | Decide **completed prior event / manner-accompaniment / maintained background**, inspect minimal contrasts in `event-linking.md` and compare a full predicate example. Check `lier` directional use separately. | Choose the matching construction and retain the event sequence and participant roles. |
| Negation/modal suffixes appear stackable from separate word glosses | Determine which operator has scope over which event, check positive–negative pairs and suffix ordering in `aspect-modality.md` / `clause-patterns.md`. | Use an attested whole-predicate combination; otherwise split into two supported clauses or mark a single provisional construction. |
| A Chinese adjective appears usable as a Tujia noun or attributive modifier | Find the lexeme's predicate/derived form and check its attributive, nominalized and independent-reference examples in `clause-patterns.md`. | Use the source-supported adjective/relative-clause/nominalization path for that syntactic role. |
| Nominalizers `-ma`, `-xi`, `-ci` or source classifiers seem freely interchangeable | Decide referent (agent, object, event, thing, location), and check an attested pair with the same head and argument gap. For classifiers, search source count phrases and source English glosses. | Use the licensed suffix/classifier; when the class is unresolved, paraphrase with an explicit **人 / 东西 / 地方** construction if licensed, or borrow the complete Chinese numeral–classifier phrase with clear provenance. |
| A bare glossary cannot establish optional markers or free word order | Retrieve a **complete source sentence**, compare the marker's role before/after substitution and check word order in `clause-patterns.md`. | Keep the original attested frame or use another fully supported frame. |
| A Chinese verb–object loan would retain Chinese SVO order | Separate the event's object and predicate; place them in the selected Tujia SOV/marked frame, attach negation/aspect to the predicate as licensed. | Preserve lexicalized compounds only when the source evidence supports them as units. |
| No attested native equivalent is available after bounded checks | Try a plain native construction; next use a clearly visible Chinese lexical insertion fitted to Tujia syntax (noun, predicate or whole numeral–classifier phrase as appropriate). | Deliver every clause, with only localized missing phonetics and one global quality note. |
| A small sound/word fragment appears only in a gloss alignment | Reopen the **full attestation** and inspect syllable boundaries, original form, linked notations and local grammatical role. | Use the verified whole word; otherwise replace it with a known paraphrase or a visible Chinese slot—never synthesize a syllable. |
| Tone, IPA, notation pairing, or source-specific conversion is missing | Use `notation-audit.md` plus the original attestation's matching IPA/romanization pair; preserve the original IPA and verify its conversion. | Give **调号拼音 then IPA** for all verified spans, use a narrow Chinese insertion/unknown-tone marker for the rest; show Ye **only on request**. |
| Multiple IPA readings or accents disagree | Keep source/locality-specific versions distinct, compare their phonological profiles and the same-attestation mapping. | Choose the best-supported source-aligned rendering and note the specific conflict once, rather than silently averaging tones. |
| A native expression seems unnatural merely because it is new | Verify the productive syntax, source-defined selection restrictions and semantic roles; compare a parallel sentence if available. | Output a **拟译** with a single overall speaker-review caveat; do not require exact whole-sentence corpus attestation. |
| A long task is still retrieving evidence | Share an actual found word/construction and the first drafted clause in a user-visible progress update; then continue with cached records. | Send another substantial passage before the final complete translation, instead of generic status ticks. |
| A score, citation, native-speaker review or “latest dictionary” status cannot be established | Recheck current command results, source manifest and audit identifiers. Cite the actual snapshot and state whether retrieval was Embedding / Skill-based / Mixed. | Use **拟译 / 需母语者审阅** as one global note and omit unsupported metrics or claims. |
| Public service would require per-request model inference, gzip decompression or dictionary-wide scans | Build the embeddings and static shards **offline**, serve bounded CDN-cacheable static files, add caching/request limits; use `tujia-lex` locally for bulk work. | Keep public endpoints read-only and bounded; move heavy jobs to scheduled/offline builds. |
| A requested source is private or only licensed for reading | Use the data locally for the authorized task and retain a private citation/attestation ID. For a public package, include scripts and pointers to authorized public sources rather than reproducing the restricted material. | Publish only after explicit authorization; otherwise deliver the translation without redistributing source material. |

## Exploration budget and escalation

- **Per unfamiliar lexical concept (ordinary translation):** one exact query + one BGE raw/decomposed batch, or up to 8–12 deduplicated synonym-lite exact candidates. Inspect promising witnesses; if none fit, move to a compositional construction / targeted Chinese slot.
- **Per grammatical question:** one `grammar-index.md` route, then one source-backed minimal contrast (or a second route only for a real scope conflict). If still unresolved, choose the best-supported provisional clause and record what remains uncertain.
- **Per source conflict:** one same-attestation review, then one independently documented local/Brassett comparison; stop cycling through similar glosses.
- **For lengthy or explicitly academic audits:** expand these budgets for meaningful new evidence, but log **what new evidence would change the choice** before each additional search.
- **Completion rule:** decide, draft, and continue. Every blocker must end in a usable candidate, a supported paraphrase, an explicit borrowing, or a precisely scoped unresolved pronunciation/construction—not stalled output.

## Quick examples

- `猜忌` → query 嫉妒 / 怀疑 / 不相信 (label differences) → inspect the exact witness → choose an attested mental predicate plus a suitable complement rather than forcing a Chinese compound.
- `追悔莫及` → search 后悔 + 伤心/心痛 + 已经无法挽回 → compose a sequence of a realization and emotional/result clause; use only supported polarity/modality.
- `饮料` → 喝 + 东西 → check event-to-object nominalization (`hu-ci` as a **hypothesis to verify**) → compose, with Chinese insertion only if productive nominalization is unsupported.
- `快要` → impending event vs impending completion → `aspect-modality.md` prospective/inchoative, not a universal separate adverb.
- `叶氏拼音来源但没有可靠 IPA` → inspect same-attestation notation/converter → print verified tone-marked spelling and IPA spans; mark the missing portion rather than fabricate one.
