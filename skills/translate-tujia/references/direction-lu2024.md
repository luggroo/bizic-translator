# 趋向：先判位移、语气和动作是否发生（鲁美艳2024资料剖面）

来源：鲁美艳《土家语趋向词研究》，《广西民族师范学院学报》2024年第41卷第6期，61–67页，DOI：10.19488/j.cnki.45-1378/g4.20250206.002。PDF第1–7页对应印刷第61–67页。

本文给出六个动词后的附着成分：`ti⁵⁵、tiu⁵⁵、ɕie⁵⁵、ɕiau⁵⁵、lie⁵³、lu²¹`。作者称其为“趋向词”；下文的“后缀”指这种后接位置。全文未交代具体调查点、说话人或南北部方言归属。作者简介的“湖南龙山人”是作者籍贯，不能作为全部例句的调查点证明。

本剖面的形式、调值及搭配条件属于鲁2024。它们与 Brassett 2006/2004 的音形、体貌分析及后置成分表**不可机械互换**。本来源只有IPA，没有可独立核对的调号拼音；引例保留来源记音，不据IPA反推一套口音拼写。数字改成上标仅为排版。文本层的无点字母 `ı` 等疑难字形及印刷矛盾另列，未作推定修复。

## 1. 可执行的选择顺序

### 起点：选择资料剖面

只有采用鲁2024资料剖面时，才执行下文六词的句类、已发生义和替代否定规则。采用 Brassett 剖面时，回到该来源自身的原例和分析，不能因词形相似把鲁2024的 `tiu/lu`“已发生”限制移过去。同一句若缺足以选择剖面的证据，先保留这项来源差异。

### 第一步：确定谁发生空间位移、以哪里为参照

将输入分析成“谁移动／什么移动、到哪里、动作V是什么、发话时是否已发生、语气、肯否定、是否已回原点”。路径还要分别记录 UP／DOWN／IN／OUT（上、下、进、出）与 TOWARD／AWAY（朝向、背离立足点）。后缀只证明向心或离心时，不能仅靠它补出“向上／向内”等路径；先从同来源的动词、处所或完整构式落实这项意义。本文特别列出的“站起来／蹲下去”属于有整例支持的垂直用法。不及物V通常跟踪施事；及物V可能跟踪施事、受事或两者。不要从“及物”直接推出“两者一起移动”。例如“寄信去”跟踪信，“背水来”跟踪人与水。

原文依据（61页，引言）：“当动词是不及物动词时，趋向词表示施事的位移方向；当动词是及物动词时，趋向词表示施事、受事或施事与受事共同的位移方向。”参照点“通常都是以说话人所在的位置为立足点”（61页）。“通常”保留语境余地；本文未给完整的立足点转移规则。

### 第二步：先分三种事件，再用语气和发生状态选形式

| 事件与语气 | 本来源选择 | 使用条件 |
| --- | --- | --- |
| 朝说话人来；陈述／疑问 | `V+ti⁵⁵` | 裸式已有事例多表示说话前发生；未然动作后接 `xu⁵³` 即行体或 `-ɪ` 将行体；原文另有 `V+ti+to²¹`“应该来V” |
| 朝说话人来，明确动作已发生；肯定陈述／疑问 | `V+tiu⁵⁵` | `tiu` 兼带已发生义；不直接放在否定式中 |
| 要求朝说话人来；祈使 | `V+ɕie⁵⁵` | 这是向心用法；禁止式为 `tʰa⁵³+V+ɕie` |
| 施事去别处做V，而且已经回到原点；肯定陈述／疑问 | `V+ɕie⁵⁵` | 已完成往返；原点是施事出发点，不必推成说话人当前位置 |
| 同样已完成往返，强调V已发生；肯定陈述／疑问 | `V+ɕiau⁵⁵` | 与往返 `ɕie` 的差别是已发生义的强调；不是“即将来做V” |
| 背离说话人去；动作尚未发生；祈使 | `V+lie⁵³` | 祈使不另加即行体 `xu` |
| 背离说话人去；动作尚未发生；陈述／疑问 | `V+lie⁵³+xu⁵³`（通常） | 原文的强度为“通常”，并未给出所有不带 `xu` 的例外条件 |
| 背离说话人去，动作已发生；肯定陈述／疑问 | `V+lu²¹` | 已发生，不用 `lie` 表这项意义；否定时改用下述替代构式 |

“来做V”与“去做V并已回来”按**位移路径、语气、发生状态**分开。`pa⁵³ti²¹` 在原文“姐姐看我来了”中为朝说话人来看的事件；`jie²¹zɿ⁵⁵ɕie⁵⁵` 在疑问句“你去干活了？”中包括出发、做事、回到原点。相同 `ɕie` 在祈使句才是向心请求。汉语的“了”或句末标点不足以独立选形式。

强条件的原文：

- 62页一（一）：“当ti55前的动作是尚未发生的未然动作时，其后必须加即行体助词xu53[2]或表将行体的附加成分-ɪ”。该段未解释63页例9 `V+ti+to²¹`“应该来看”的关系；保留此有证据的情态构式，不把 `ti` 简化成过去时，也不外推任意情态例外。
- 64页二（一）1在向心小节说：“ɕie55只能用于祈使句”；二（一）2说：“ɕie55表示往返趋向义时，只能用于陈述句和疑问句的肯定式。”此处“只能用于祈使句”限定向心用法。
- 64页：“往返趋向仅指向动词的施事”，并“隐含着‘施事已经回到了原点’”。它不额外断言受事也完成同样往返。
- 65页二（二）：“ɕiau55比ɕie55更具有强调动作行为已经发生的意味。”67页结语明确两种往返形式都只用于陈述／疑问。
- 66页三（一）：“其前动词所表示的动作只能是尚未发生的未然动作。”`lie` 的句类本身不限陈述、疑问、祈使；`lu` 只用在肯定陈述／疑问（66页）。

人称：本文未提出某后缀只许第一、第二或第三人称的规则。例句中的人称是例证，不构成人称范式。

### 第三步：垂直位移同时核对立足点

本来源列出向心 `ti`、祈使向心 `ɕie` 的低→高用法，常译“起来”；`lie` 有高→低用法，常译“下去”；`lu` 有“掉下去了”的已发生例。

**“站起来”的固定条件**见62页一（一）例2：`ʦu⁵⁵ʦu⁵³ti²¹` 表明说话人当时已经站着，“否则ʦu55ʦu53‘站’后只能用离心趋向词lie53”。所以不能仅凭“起来”两字一律选 `ti`；该例的说话人姿态决定形式。本文未给坐着、躺着、叙事视角等完整垂直范式，也没有明说这条具体条件在 `ɕie` 祈使式中如何全面推广。优先复用相同站姿语境的原例。

## 2. 否定：保留正确语气和动作作用域

| 肯定构式／意图 | 否定或禁止构式 | 本来源限制与意义 |
| --- | --- | --- |
| 向心 `V+ti` | `V+ti+NEG` | 能愿词及否定副词均位于动趋结构后（63页一（一）例9–10） |
| 已发生向心 `V+tiu` | 改为 `V+ti+tʰa⁵³/ta⁵⁵`，句末通常加 `nie⁵⁵` | `tiu` 本身仅肯定；不要直接 `tiu+没`（63页一（二）例3–4） |
| 向心祈使 `V+ɕie` | `tʰa⁵³+V+ɕie` | “别来V”；否定词在V前（64页二（一）例5–6） |
| 已往返 `V+ɕie` | 改为 `V-ɪ+pu⁵³ʦʰɣ²¹` | “没去V”；替换后只表单向位移，**不再隐含往返**（65页二（一）例9–10） |
| 强调已往返 `V+ɕiau` | 改为 `V-ɪ+ta⁵⁵`，句末通常加 `nie⁵⁵` | “还没去V”（65页二（二）例3–4）；没有保留肯定往返后缀 |
| 离心祈使 `V+lie` | `tʰa⁵³+V+lie` | “别把……带去”；否定在V前（66页三（一）例8） |
| 离心非祈使 `V+lie` | `V+lie+tʰa⁵³+nie⁵⁵` | 例9是“还不把……抱走？”；同一 `tʰa` 的位置随祈使／疑问而变 |
| 已发生离心 `V+lu` | 改为 `V-ɪ+ta⁵⁵`，句末通常加 `nie⁵⁵` | “还没V去／掉下去”（66页三（二）例3–4） |

65页明确说明：“将ɕie55替换成附加成分-ɪ以后，‘动词+ɪ’不再隐含往返趋向义，仅表示单向的位移。”因此“没有往返成功但已经去过”或“去了尚未回来”不能自动套作原文这两条“没去V”的负句；本文没有给出这些细分事件的完整编码。

`-ɪ` 在62页例6标 `PROS`（将行体），在65–66页否定式标 `SHIS`（位移）。保留各例的功能和附着位置，不从形似推定所有用法同义。`nie⁵⁵`“还”在这些否定构式中常用，原文没有把它写成每条负句不可省的必要成分。

## 3. 次序、处所和定语

- 向心 `ti/tiu/ɕie` 的起点：处所名词＋`lie⁵⁵`（ABLP）在动趋结构前；这里的源点 `lie⁵⁵` 与离心后缀 `lie⁵³` 分开。
- 离心 `lie/lu` 的终点：处所名词＋`po⁵⁵`（ALLP）在动趋结构前。
- 向心未然：`V+ti+xu⁵³` 或 `V+ti-ɪ`。离心未然陈述／疑问通常是 `V+lie+xu⁵³`。
- `V+ti` 后接能愿／否定；禁止向心、离心祈使的 `tʰa⁵³` 则在V前。不要把陈述否定词序照搬到祈使句。
- `V+ti+nie⁵⁵+ɕi⁵⁵+N`：63页说定语用法“通常”加两助词；`V+tiu+nie⁵⁵+ɕi⁵⁵+N`：63页说“必须”加两助词，64页有原例。
- `V+lu` 的定语原例见67页。例7为 `lu²¹nie²¹ɕi³⁵`，例8为 `lu²¹nie⁵⁵ɕi⁵⁵`；本文未给这项异调的条件，不能据这两句制造自由替换规则。

这份论文只支持上述局部组合；它没有给六个趋向词与所有体、情态、否定的完整后缀位置表，也没有证明可与 Brassett 的十位置表直接拼接。
