# 趋向：从词义和完整构式选择表达

本页按来源列出趋向的词形、整例与适用范围。先区分移动路径、来去参照点和目的地；上、下、进、出等原义由相应动词或趋向构式落实，处所短语标明位置或目标。返回、显现和引申结果按完整构式选择。

参考语法：[位置与动作的方向](https://tujia.biz/#grammar/north/104?grammarAnchor=north-14-3)、[拿来与拿走](https://tujia.biz/#grammar/north/104?grammarAnchor=north-29-102)、[完成向心与完成离心](https://tujia.biz/#grammar/north/104?grammarAnchor=north-29-101)。

## 离心选形

表达离心时，采用 `V-lie` 或 `V-i`，按所需语义和来源构式择一；不叠成 `lie-i`。动词、目标短语与所选构式共同落实谁移动、到哪里及动作阶段。主语去异地做V、受事被运送以及纯将行的选择见[动作与位移结构](event-linking.md#motion-event-frames)和[-i的用法](aspect-modality.md#i-functions)。

`lie` 的完整体、连动、来源格、给予动词和离心功能，按句法及来源标签辨认；连读的55／21与前调有关，具体见[助词变调](aspect-modality.md#particle-sandhi)。

## 3. 鲁2024：读清语气、已发生与往返

需要使用鲁2024体系时再读 [六词详表、否定和原例](direction-lu2024.md)，先用下面的小表定位。

| 目标意义与语气 | 该论文体系中的选择 |
| --- | --- |
| 向心，陈述／疑问 | `V+ti`；动作未发生时核论文的 `xu`／将行 `-ɪ` 搭配；义务结构另有整例 |
| 向心且动作已发生，肯定陈述／疑问 | `V+tiu` |
| 向心祈使 | `V+ɕie`；禁止式为前置 `tʰa+V+ɕie` |
| 施事去做V且已经回到原点，肯定陈述／疑问 | `V+ɕie`；`V+ɕiau` 更强调V已发生 |
| 离心未然祈使 | `V+lie` |
| 离心未然陈述／疑问 | 通常 `V+lie+xu` |
| 已发生离心，肯定陈述／疑问 | `V+lu` |

否定时，论文的 `tiu` 换 `ti` 再接否定；肯定往返的 `ɕie/ɕiau` 及已发生离心 `lu` 改用 `V-ɪ+NEG` 等原文构式。往返替换式不再隐含已回原点。论文还记录具体的垂直位移和说话人站姿条件，以及多处文字规则与印刷例句的声调冲突；详表逐项保留，不以规则预测值冒充原例。
