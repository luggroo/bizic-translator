# 土家语翻译：语法检索入口 / Grammar lookup index

**先读本页，再按语义跳到一个专题。** 这是 `translate-tujia` 的入口，不是另一份线性语法。目标是**最少文件读取、最少重复检索**，不是要求模型每次通读全部 reference。

**优先级**：① 匹配已有完整例句的语义和谓词类别 → ② 检查组合限制 → ③ 用指定本地词库找新的词项 → ④ 只有新构式或来源冲突才检索新的例句。不要让常见 `liex/mor/bor` 或 TAM 问题反复触发长时间语料搜索。

## 2. 统一的例句展示标准

- **调号拼音**是所有 reference 的首选展示形式，后面必须有**逐句对应的 IPA**；文献地点、页码和例号同时保留。
- 叶氏拼音只用作检索别名／解释原始文献记号，不以它替代例句的调号拼音。主 Skill 输出翻译也默认**调号拼音＋IPA**，用户明确要求才展示叶氏拼音。
- **来源不同，不把音系强行归一**。原文缺调、只给部分 IPA、IPA 与调号冲突时，在例句表格标 `⟦待核⟧` 并放进核验记录；不能把有问题的 IPA 默默修改成拼音所暗示的音值。
- 每张有土家语例句的表至少包含 `调号拼音 | IPA | 汉义 | 出处`，不出现只列无调拼音或只列 IPA 的“已经核实”例句。分析性的抽象音位和语法符号可写 IPA，但它们不是引用例句。
- 严格区分：Brassett 2006 原例 / 其他北部来源 / 南部来源 / 未刊补充资料 / 按规则组合的教学例句。归属不是发音许可证。

以上双转写要求适用于规范化例句表。文献对照中的原文引语保留原记音；Feng 等原文未标调时保留无调形式，通过 [notation-audit.md](notation-audit.md) 记录缺失，不从另一来源补调。
