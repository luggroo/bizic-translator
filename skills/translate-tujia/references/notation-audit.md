# 调号拼音与 IPA 核验

无执行工具时，采用[网页见证流程](web-evidence.md)：保留页面中与所选见证相连的拼写、IPA 和 source/derived 等处理标记。本地转换记为 `not_executed`；已发布形式不等于本次脚本校验成功。若只取得原记音，明确标为原记音，把未取得的目标拼写或 IPA 标为待核；调号说明不替代来源专属转换脚本。

把同一 attestation 的拼写、IPA、来源、调查地点和转换方法保存在一条证据记录中，用于逐句对照。

## 1. 来源与显示

- 引例表使用 `汉义 | 调号拼音 | IPA | 来源 | 解释`，保留完整例句或最小片段、词界、子句顺序、页码和例号。
- 北部显示调类采用来源 profile：`55/44` 为高平，`24/35/325` 为升，`21/214/31/33` 为低／转，`51/53/54` 为降；IPA 保留原记录的实际调值。
- 南部按对应来源转换：`55`及特定来源的`53/51`→横线，`35`→锐音，`21`→重音，`13`→曲折，`33`及部分来源换算的`31`可无可见符号；舌尖元音与 `ɨ/i/ei` 根据来源和声母环境处理。
- 对照实际译文，按同一见证的已知调值逐音节核对显示调类与调号，同时核验声母（含 `ɣ/x`）、送气、鼻化、韵部、音节边界、无调小词及融合。
- 按语法功能、来源基记、前调环境及完整构式辨认各处 `lie`、`bor` 等成分；语流调值见[助词变调](aspect-modality.md#particle-sandhi)。
- 选择原文对照、同 attestation 配对或带来源的转换结果；在内部记录采用的转换方法。叶氏拼音用于检索键、溯源或用户明确指定的输出。

### Brassett 2006 的 h

第10页表2.2明确将 /x/ 在所有环境的实现记为 [x]；第24页表2.34以 `hu³`“喝”示例，IPA为 /xu²¹/。书写 h 及其派生形式依这一对应核验。来源专属的字母、音位与表音层级分别保留。

## 2. 核验步骤

1. 定位原始 attestation，读取其方言、调查点、完整词形和关联记音。
2. 复用经来源核定的拼写／IPA 配对；派生字段按已核本源规则及转换器复核。
3. 比较音节数、词界、声韵和调值，分别记录词表形式与语流形式。新的字形、调号或词序冲突涉及原例判读时，核对相应原页图片；记录页码、例号、原字面和选用形式，并将核定结果保存到对应语法话题。
4. 选择可用的完整词形组织译句；汉语夹用成分保留汉字。

## 3. 自动检查与原始材料核对

`python scripts/check-grammar-skill.py` 检查表格的双转写列、显示调类、来源标注、参考路由和打包内容。派生拼写在表头记录转换方法，例如“拟转写：由 IPA 派生”。静态检查验证转换的一致性；来源读音通过同一 attestation 的独立配对、原始文献或录音校对。

## 4. 核验记录

记录出处与原字面、地点与 attestation ID、拼写／IPA、问题类型和选用形式。保留原引文及修订依据；尚缺独立证据时保留来源版本并标明具体待核项。将核定的规则和适用条件保存到对应话题。普通译文按 [output.md](output.md) 交付。
