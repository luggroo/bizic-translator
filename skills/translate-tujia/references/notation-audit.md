# 调号拼音与 IPA 核验

无执行工具时，采用[网页见证流程](web-evidence.md)：保留页面中与所选见证相连的拼写、IPA 和 source/derived 等处理标记。本地转换记为 `not_executed`；已发布形式不等于本次脚本校验成功。展示顺序与记音选择遵循[输出规范](output.md)。调号说明不替代来源专属转换脚本。

把同一 attestation 的拼写、IPA、来源、调查地点和转换方法保存在一条证据记录中，用于逐句对照。**实词调值依词条；非固定调的词缀／格助词在新拟句中可无调书写。**

## 调号拼音的取得与静态降级

- 调号拼音使用同见证的站点／参考配对，或站点来源专属转换器结果。没有固定声调的语法成分（如词缀、格助词）可按无调形式呈现；词典里的声调是基记，按原引例保留。
- Brassett 原书字母作为来源见证，站点显示拼音和叶式拼音分开处理。叶式拼音只按用户指定输出；优先按 Feng 的明示规则或文献例句，随后使用来源专属转换器。
- 静态分片 v2 的 `term` 已在导出时统一为调号拼音或 `/IPA/`，`term_notation` 为 `accent`、`ipa` 或 `missing`；`notations` 只含同见证的 `accent` 与 `ipa`，数组顺序不构成逐项配对证据。`source_term` 仅供溯源，旧版分片须重建。


新拟汉借词另按[离线补音](loan-pronunciation.md)查询；所得为 `proposed-loan-mapping`，保留源字音与整词缺字处理，不能作为已有词条见证。

## 1. 来源与显示

- 引例表使用 `汉义 | 调号拼音 | IPA | 来源 | 解释`，保留完整例句或最小片段、词界、子句顺序、页码和例号。
- 北部显示调类采用来源 profile：`55/44` 为高平，`24/35/325` 为升，`21/214/31/33` 为低／转，`51/53/54` 为降；IPA 保留原记录的实际调值。
- 南部按对应来源转换：`55`及特定来源的`53/51`→横线，`35`→锐音，`21`→重音，`13`→曲折，`33`及部分来源换算的`31`可无可见符号；舌尖元音与 `ɨ/i/ei` 根据来源和声母环境处理。
- 对照译文核对实词声韵和调号、词缀与格助词的边界、无调成分及合音。固定调与随语流变调的成分分别处理，**无固定调值时无需补填**。
- 按语法功能、来源基记、前调环境及完整构式辨认各处 `lie`、`bor` 等成分；语流调值见[助词变调](aspect-modality.md#particle-sandhi)。
- 选择原文对照、同 attestation 配对或带来源的转换结果，并在内部记录转换方法。

### 本站统一 IPA 记号

采用同一见证的 `notations.ipa`；`source_term` 保留原文，不能用它覆盖本站统一形式。与原文不同的记法集中说明于[拼写对应页](https://tujia.biz/notation.html#notation)。

| 原记号与环境 | 本站 IPA | 保留的区别 |
| --- | --- | --- |
| ɳ、ɲ、ɲ̟ | ȵ | 不改声调与音节界 |
| ts、tsʰ、dz、s、z 等平舌咝音后的独立 ɨ | ɿ | k、kʰ、x、ɣ、t、d 等音后的 ɨ 保留；ɨe 等复合韵母保留 |
| tʂ、tʂʰ、dʐ、ʂ、ʐ 等卷舌咝音后的独立 ɨ | ʅ | 与平舌音后的 ɿ 分开 |
| Brassett IPA f | ɸ | 其他来源 f 和叶式调号字母 f 保留 |

### Brassett 2006 的 h

第10页表2.2将 /x/ 的实现记为 [x]；第24页表2.34的 `hu³`“喝”原书 IPA 为 /xu²¹/。本站统一记号采用 /ɸu²¹/，`hua、huan、hui` 等同样以 /ɸ/ 起首；`ha` 仍对应 /xa/。引用原书时保留原记音，译文和词库显示使用本站形式。

## 叶式拼音（按需）

**叶式拼音按用户请求输出**：用 Feng 的记音规则或同来源例句选词缀、格助词的写法。例如 Feng 例27a 的 `niexi` 独立指称与例27b 的 `nie＋N` 分别按原例记音；无固定声调的成分保留无调。默认调号拼音直接按站点的源记录写出。

## 2. 核验步骤

1. 定位原始 attestation，读取其方言、调查点、完整词形和关联记音。
2. 复用经来源核定的拼写／IPA 配对；派生字段按已核本源规则及转换器复核。
3. 比较音节数、词界、声韵和调值，分别记录词表形式与语流形式。新的字形、调号或词序冲突涉及原例判读时，核对相应原页图片；记录页码、例号、原字面和选用形式，并将核定结果保存到对应语法话题。
4. 选择可用的完整词形组织译句；汉语夹用成分保留汉字。

## 3. 自动检查与原始材料核对

`python scripts/check-grammar-skill.py` 检查表格的双转写列、显示调类、来源标注、参考路由和打包内容。派生拼写在表头记录转换方法，例如“拟转写：由 IPA 派生”。静态检查验证转换的一致性；来源读音通过同一 attestation 的独立配对、原始文献或录音校对。

## 4. 核验记录

记录出处、地点、attestation ID、拼写／IPA 与实际采用的形式；查明的新规则保存到对应专题。普通译文按 [output.md](output.md) 交付，调值缺口与语法分歧集中在总体说明。
