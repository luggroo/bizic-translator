# 调号拼音—IPA 核验规则 / Notation audit

**目标**：让所有翻译语法 reference 默认采用 **调号拼音（首选可阅读形式）＋对应 IPA**，而不是以无调叶氏拼音／IPA 单独引用例句。对照表应成为发现 IPA 与拼写不一致的证据，而不是自动将 IPA 当作无误的原始“答案”。

## 1. 阅读和录入标准

- 有引用例句的表格使用 **`汉义 | 调号拼音 | IPA | 来源 | 解释`**；每行包含完整原句或最小引用片段，分词和子句次序相同，来源指到作者、页码和例号。若参考语法有“拼音／IPA”成对表，优先直接用这一对来源数据。
- **调号拼音不是旧叶氏拼音**：前者使用该网站的附标方案（北部的四类调号是横线、锐音、曲折、重音；南部方案另行处理）。旧式 `x/f/r/v` 只能用于隐藏的检索键、转写溯源、或用户明确要求时显示。
- **IPA 永远保留来源的实际调值**。北部对应的四组显示调类大致为 `55/44`→高平、`24/35/325`→升、`21/214/31/33`→低/转、`51/53/54`→降；**这是显示约定，不是宣称声学调值同一**。其他来源及南部转写不允许套用北部规则。
- **南部**（本站规则）可见调号：`55`（以及特定来源的 `53/51`）→横线；`35`→锐音；`21`→重音；`13`→曲折；`33` 和部分来源换算的 `31` 可无可见符号。舌尖元音、`ɨ/i/ei` 的拼写依据**来源 + 声母环境**，不能由北部音系表自动决定。
- **音值检查不止调类**：核对声母送气、/ɣ/ 与 /x/、鼻化元音、韵部、音节数、边界、送气的上标 `ʰ`、无调小词及词缀。声调看上去匹配不等于 IPA 的声韵就正确。
- 同字母表中容易误判的例：北部传统别名 `liex` 的 /lie⁵⁵/（完整体）与 `lier` 的 /lie²¹/（趋向）；传统 `bor` 在不同句法位置对应不同调号／关系。检索时这些别名可以保留；**例句始终以调号拼音呈现**。
- **参考来源优先级**：Brassett 2006、Brassett 2004、同地点的实录；来自陈康、田志慧、鲁曼、Feng 和南部方言的例句单独保持其来源范围，不反向“纠正”Brassett 的口音。

## 2. 自动质检做什么、做不到什么

`python scripts/check-grammar-skill.py` 检查所有 `references/*.md` 中的实证双转写表格：

1. 表格是否**同时有 `调号拼音` 和 `IPA` 列**；正文例句必须带来源。
2. 依据对应方言的显示调类比较每个有标音节：调号拼音的标记数量、顺序是否与来源 IPA 的超标调值相容。**发现不一致应报文件名、行号和整行**，不能在检查器里自动改正 IPA。
3. 检查是否有注释注明“由 IPA 反推、待独立核验”，否则不能把仅由 IPA 生成的调号拼音当成独立验证的证据。
4. 防止用户没要求时在示例表格输出叶氏拼音或旧式无调拼写。只有明确标为“检索别名”的术语不属于完整引例。
5. 检查 Skill 打包是否包含最新检索入口与专题参考，避免新增 reference 本地可见、发布时丢失。

**边界**：这个检查是基于元数据和音标的静态一致性测试，不能代替音频、文献图版或说话人核对。如果调号拼音本来就是**从同一 IPA 转写出来的**，两者的形式一致只能说明转换算法没有明显出错，**不能反证来源 IPA 正确**。独立校验必须找同一 attestation 在网站词典的拼音/IPA 配对，或核对原始文献与录音。

## 3. 待核样例（不是自动“修正结果”）

| 疑点 | 建议操作 | 为什么不能猜 |
| --- | --- | --- |
| 补充口语 `gafliao`：参考语法明确留空了 `liao` 的声调 | 回查同一说话人原始记录；保留缺调说明 | 不能从别的方言 /liau⁵⁵/ 机械补上 |
| Feng（2025）部分定语／独立指称例句未标调 | 保留原图文字和原文 IPA，另找核验材料 | 不能给 `nie-xi` 等一律加定音 |
| `liex` 与 `lier` 在某些无调记录中都简写 lie | 先问是完整体还是趋向，分别核 IPA 和调类 | 音节相同不代表词义和句法相同 |
| 同一北部词条的 IPA 记录分别出现 /kuɔ²⁴/、/ko³⁵/ 等 | 比较来源、地点、语境、词项及转写惯例 | 不同调查点与文献体例不一定是“谁写错” |
| 仅 IPA 的 Brassett §9.3 句例（如“笑着走”“坐着吃饭”） | 目前参考以“拟转写，待独立核”并列标注，之后用原始出版物核验 | 不能拿从 IPA 推出来的拼音再证明那个 IPA |

## 4. 新发现错误时如何处理

给每个冲突留四项：**出处与原字面、拼音/IPA 两栏、冲突类型（调值、声韵、拼写、方言、缺证）、处理结论/待核**。优先更正可独立验证的转录或音节分界；不能验证时保留版本并标 `⟦待核⟧`，绝不默默在两个格式里任选一个。原始引用在资料内部仍保留，以支持追溯，但默认用户可见的译文只给调号拼音＋IPA。
