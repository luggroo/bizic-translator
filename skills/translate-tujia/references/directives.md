# 祈使与指令：构式选择 / Directive constructions

适用北部／龙山土家语。先辨别命令、请求、劝请、禁止，再判断即时性、必要性、结果状态和运动方向。普通祈使可以用裸动词及语调表达；汉语“请、吧、了、马上”不各自对应固定词尾。南部方言另查南部例句。

<a id="choose"></a>
## 1. 先选语义，再选构式

1. 判断言语行为（是否要求听者行动）及参与者（听者、包含说话人的“我们”）；“他应该走”是必要性的陈述，不是直接祈使。
2. 分开标记 **immediate**（现在开始／停止）、**necessity**（应当／必须）、**state**（保持状态）、**direction**（朝向／离开参照点、谁在移动）。
3. 先匹配以下有证据的结构。若无额外语义，优先裸 V。多个后置成分只有在同来源整例或明确能产构式支持时才组合。
4. 禁止先辨[否定作用域](#prohibition)，有空间位移先查[趋向专题](direction-suffixes.md)及[鲁美艳2024](direction-lu2024.md)。

| 需要表达 | 优先构式 | 依据／解释 |
| --- | --- | --- |
| 一般命令或请求 | 裸 `V` | 不必有显性祈使标记（B06:89–90） |
| 立即做、现在停止、马上行动 | `V-gu` | 即时指令；可用于命令、禁止、包括说话人的劝请（B06:135–137） |
| 应当做、必须做、带义务的劝行 | `V-do` | 例如 `ángnī hxí dǒ`“我们该走了”（B06:90例113） |
| 保持坐着、放着、打开状态 | `V-bo` | 状态保持 `STAT`，指令语气由整句表达（B06:90） |
| 把物品拿来／向参照点移动 | `V-xie` | 向心（B06:119–121） |
| 把物品拿走／向别处移动 | `V-lie(DIR)` | 离心；与完整体 `lie(PFV)` 不同（B06:120–122） |
| 别做、不要做 | 前置 `ta + V` | 禁止（B06:91）；即时禁止可用有整例的 `ta + V + gu` |

<a id="gu"></a>
## 2. 独立 gu：即时指令

Brassett的 **gu² /ku²⁴/** 独立出现于命令、禁止、劝请，见例（190–193、200–201）。李启群等（2021）《土家语汉语词典》的 **ku⁵⁵**（助词）条明确归于祈使句，表示动作从说话时开始并起句末煞尾作用；两套调值按来源分别保留。

本 Skill 将独立 `gu` 标为 `DIR.IMM`：例如 B06例191“现在把那个给我”、例193“现在别回家”。`liao`、`diu` 等完成／趋向形式按各自的完整例词选择。

| 资料中的完整形式 | 汉义 | 来源及作用 |
| --- | --- | --- |
| `aixdix ngaf bor lief guf` | 现在把那个给我！ | B06:135例191：即时命令 |
| `nif tav songxkox guf` | 现在别回家！ | B06:135例193前半：禁止＋即时 |
| `ta⁴ ong³ bo³ gu²` | 别再坐着了 | B06:135例190：状态 bo＋gu |
| `ri¹ lie¹ gu²` | 现在把它做完！ | B06:137例200：此 `lie¹` 为 PFV，非离心 |
| 例193后半：“我们一起好好玩吧” | 第一人称复数劝请 | B06:135：gu 不局限于第二人称 |

表格沿用 Brassett 及参考语法的原拼写。原书拼音／IPA 例证见[参考语法 gu 小节](https://tujia.biz/#grammar/north/105?grammarAnchor=north-directive-gu)。

<a id="do-bo"></a>
## 3. do 与 bo 的决定因素

| 调号拼音 | IPA | 译义及分析 | 来源 |
| --- | --- | --- | --- |
| ángnī hxí dǒ | /ã²⁴ɲi⁵⁵ ɣɨ²⁴ tuɔ²¹/ | 我们走吧：必要／劝行 | B06:90例113 |
| ǒng bǒ | /ɔ̃²¹ pɔ²¹/ | 坐下并坐着：STAT | B06:90例110 |
| cīpū tóng bǒ | /tsʰɿ⁵⁵pʰu⁵⁵ tʰɔ̃²⁴ pɔ²¹/ | 打开书并保持打开：STAT | B06:90例112 |

“我们该走了”用必要 `do`，如 `ángnī hxí dǒ`；“现在就行动”用 `gu`，如 B06例191；“坐着别起来”用状态 `bo`，如 `ǒng bǒ`。缓和请求“讲一下”参见[尝试与缓和](https://tujia.biz/#grammar/north/105?grammarAnchor=north-22-101)。

<a id="direction"></a>
## 4. xie 和 lie 先选方向

| 调号拼音 | IPA | 译义 | 来源 |
| --- | --- | --- | --- |
| cīpū hǒ xié | /tsʰɿ⁵⁵ pʰu⁵⁵ xuɔ²¹ ɕie²⁴/ | 把书拿来（向心） | B06:119–121 |
| cīpū hǒ liě | /tsʰɿ⁵⁵ pʰu⁵⁵ xuɔ²¹ liɛ²¹/ | 把书拿走（离心） | B06:120–122 |

方向构式按参照点与位移者选择：**`cīpū hǒ xié`“把书拿来”**（向心），**`cīpū hǒ liě`“把书拿走”**（离心）。同形 `lie` 在 B06例200 `V＋lie(PFV)＋gu` 表动作做完，依事件关系区分。

鲁美艳（2024）另有向心祈使 `V+ɕie` 与离心祈使 `V+lie`，其句类与否定形式见[该文专题](direction-lu2024.md)。直接采用相应来源的方向构式；同时表示即时指令时优先使用已有完整例句。

<a id="prohibition"></a>
## 5. 禁止与组合

禁止采用谓词前 `ta`：B06:91例117 **`sǎ tà lǐ`“别说话”**；即时禁止采用 `ta＋V＋gu`，如 B06:135例193 **`nif tav songxkox guf`“现在别回家”**。“别吃了”按停止／劝止语义选[劝止构式](https://tujia.biz/#grammar/north/104?grammarAnchor=north-22-102)。

<a id="combination"></a>
按完整例句组合：**`ta＋V＋gu`**（B06例193：现在别回家）；**`ta＋V＋bo＋gu`**（例190：别再坐着）；**`V＋lie(PFV)＋gu`**（例200：现在把它做完）；**`V＋bo`**（例110：坐着）。新语境优先套同语义、同论元的构式。

<a id="qa"></a>
## 6. 最小对立测试（按语义选择构式）

| 测试对比 | 期望的主要选择／区别 |
| --- | --- |
| “坐！”／“坐着别起来！” | 裸式 vs `bo`（保持状态） |
| “现在就别坐在那里了！” | 禁止＋即时性；已有 `ta V bo gu` 实例 |
| “拿书来！”／“拿书走！” | `xie` vs `lie(DIR)`，先判断参照点 |
| “我们该走了。”／“我们现在就走吧！” | `do` 必要性 vs `gu` 即时指令 |
| “别说话！”／“现在就别回家！” | `ta V` vs `ta V gu` |
| “做完！”／“现在就做完！” | 体貌与即时指令分别表达；例200 `lie(PFV) gu` |
| “请讲一下。”／“现在就讲！” | 缓和请求 vs 即时指令，不把礼貌当 gu |
| “把书拿来！”／“现在把书拿来！” | 首先满足向心；无整例不自动加 `xie+gu` |

内部选形仅记录影响选择的维度：`speech_act`、`immediate`、`necessity`、`state_held`、`direction/reference_point`、`polarity`、`construction`、`source_example`。成句后按[记音核验](notation-audit.md)检查调号拼音与 IPA。
