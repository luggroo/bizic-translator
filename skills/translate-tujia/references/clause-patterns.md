# 句型、否定、性质词与名词短语 / Clause and noun-phrase patterns

**本文件解决句法结构，不提供体貌全范式。** 先从 [grammar-index.md](grammar-index.md) 路由；所有引例使用 **调号拼音＋IPA** 对齐。B06 为 Brassett 等（2006）；不混用其他方言。

<a id="negation"></a>
## 1. 否定：事实、判断、意愿、禁止，不是一个“不”

- **事实否定**（“没做、没有说”）：后置否定，例见下表。
- **意愿／判断否定**（“不去、不会去”）：与事实否定的性质和分布不同，必要时读取 [aspect-modality.md](aspect-modality.md#volition)。
- **禁止**（“别说”）：在特定记录里前置，不能照搬后置否定。
- **不是**：名词谓语的否定要使用有证据的否定判断词结构，不能因为肯定判断不用“是”就直接在名词后加普通动词否定。
- **双层否定**：“并不是不能住”之类可在带负义的情态之后另加事实否定，作用域须从整句判断。

<a id="clause-types"></a>
## 2. 判断／存在／性质谓词

| 句型 | 最先检查 |
| --- | --- |
| “他是土家人” | 名词谓语，肯定句可能没有系词 |
| “屋里有人” | 处所＋存在主体＋存在谓词，不直接套 SOV 事件句 |
| “今天冷、衣服脏” | 性质词可直接作为谓词；作定语或独立指称可能改变形式 |
| “给别人做工、对他说话” | 受益者、目标和状态后的关系标记不是同一个抽象“给”；观察具体论元与语序 |

<a id="nominalization"></a>
## 3. 性质词、名词化、量词

- “冷、脏”等基本式可以作谓词，但**不能自动等价于‘冷的、脏的’**。部分派生性质词有固定长式（如“大、长、好”的不同形态）；有些关系从句采用 /ɲie/、/ɕi/ 等组合，必须核对中心名词是否出现。
- Feng（2025）§（例27a–b）的关系化/独立指称例句原文**无调**；因此不把它们硬塞进“已核标准拼音”表。需要时按原文引例、注明缺调后再验证，不允许擅自加调号。
- 量词次序优先参考对应名词的语义类；**名词＋数词＋量词**不因借用汉语名词而改成汉语线性词序。

## 5. 仅在什么情况下继续查资料

本文件中的例句已经核过网站参考语法的拼音／IPA 对应行；不为重复证明相同构式再搜索。只有**新词性、新论元/省略结构、否定和情态共现、名词化位置、方言差异**时，才去指定本地数据库找整句。碰到 `liex/mor/bor` 的叙事关系转到 [event-linking.md](event-linking.md)，碰到“还没、不能、必须、已经”等转到 [aspect-modality.md](aspect-modality.md)。

## nie 与 niexi：显式中心词和独立指称

参见 [nie、niexi 与独立指称](nie-niexi.md)。用途物可按语境表达为“开瓶子的”一类名词化短语，避免一律添加 nie＋东西。Feng（2025）例27的独立指称 niexi 不能省 xi；带显式中心词的例27b可用 nie。领属表达、内置关系从句及其他动词短语的替换条件分别核查。
