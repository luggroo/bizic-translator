# 句型、否定、性质词与名词短语 / Clause and noun-phrase patterns

本文件处理句法与名词短语；体貌见[体貌与情态](aspect-modality.md)。 先从 [grammar-index.md](grammar-index.md) 路由；所有引例使用 **调号拼音＋IPA** 对齐。B06 为 Brassett 等（2006）；按所选方言组织词形。

<a id="negation"></a>
## 1. 否定：事实、判断、意愿、禁止，分别选形

参考语法：[事实否定与意愿否定](https://tujia.biz/#grammar/north/104?grammarAnchor=north-21-101)、[系动词否定](https://tujia.biz/#grammar/north/104?grammarAnchor=north-copula-negation)、[禁止、停止与状态不再持续](https://tujia.biz/#grammar/north/104?grammarAnchor=north-21-103)。

- **事实否定 dá**：报告事件、状态或一般习惯；B06:132例167“我不喝酒”描述不喝酒这一事实。
- **意愿／判断否定 tā**：表达特定行动的选择、拒绝或说话者对事态的判断；B06:132例172用同一喝酒谓词表达选择不喝酒。否定的作用对象与动作阶段分别确定，情态见[意愿专题](aspect-modality.md#volition)。
- **禁止**（“别说”）：在特定记录里前置，按前置禁止结构组织。
- **不是**：名词谓语后用 sǒudá /sou²¹ta²⁴/ 或 búsī /pu²⁴sɨ⁵⁵/（B06:52，例17）。
- **双层否定**：“并不是不能住”之类可在带负义的情态之后另加事实否定，作用域须从整句判断。

## 2. 判断／存在／性质谓词

参考语法：[判断词的使用](https://tujia.biz/#grammar/north/104?grammarAnchor=north-18-3)；存在、处所及论元语序见下方[关系标记](#case-frames)的参考语法链接。

名词判断的系词与否定按来源选用：sī /sɨ⁵⁵/ 见 B04 rn457678，búsī /pu²⁴sɨ⁵⁵/ 见 B06 rn454751。

| 句型 | 最先检查 |
| --- | --- |
| “他是土家人” | 名词谓语，肯定句可能没有系词 |
| “屋里有人” | 处所＋存在主体＋存在谓词，按存在句语序组织 |
| “今天冷、衣服脏” | 性质词可直接作为谓词；作定语或独立指称可能改变形式 |
| “给别人做工、对他说话” | 区分受益者、目标与状态标记，按具体论元安排语序 |

## 3. 性质词、名词化、量词

参考语法：[形容词与性质动词](https://tujia.biz/#grammar/north/104?grammarAnchor=north-6-2)。

- “冷、脏”等基本式可以作谓词，表达‘冷的、脏的’时选择相应定语或名词化形式。部分派生性质词有固定长式（如“大、长、好”的不同形态）；有些关系从句采用 /ɲie/、/ɕi/ 等组合，必须核对中心名词是否出现。
- Feng（2025）例27a–b的关系化／独立指称例句原文无调；引例保留无调记音，其转写来源见 [notation-audit.md](notation-audit.md)。
- 量词次序优先参考对应名词的语义类；**名词＋数词＋量词**同样适用于汉语名词插入。

<a id="classifiers"></a>
### 数词、量词与数量短语

按中心名词的类别选量词，核对数词与量词的组合及整个名词短语的语序。参考语法：[基数与数量](https://tujia.biz/#grammar/north/103?grammarAnchor=north-12-1)、[名量词与分类](https://tujia.biz/#grammar/north/103?grammarAnchor=north-12-2)；下表保留现成数量短语例句。

<a id="comparison"></a>
### 程度、评价与比较

区分性质的强度、对动作的评价和两项之间的比较；比较时明确比较基准、被比较项及差量。参考语法：[程度与评价](https://tujia.biz/#grammar/north/104?grammarAnchor=north-overview-degree)、[比谁更……、相差多少](https://tujia.biz/#grammar/north/104?grammarAnchor=north-23-2)。

<a id="addition"></a>
### 追加与焦点

追加另一项事件或数量时，采用与所指范围相符的追加成分。B06 的 bé /pɤ²⁴/（be²，rn455212“also”）位于其所追加的谓语前；139页例215的后半句 `guo² nie³ jie² be² die³ la¹ hu³` 表示“他的胳膊也开始要断了”。持续至某时的“还”见[持续与范围](aspect-modality.md#still)。

<a id="questions"></a>
### 疑问句

先确定是非问、选择问或成分问；成分问再区分价格、方式、原因、数量或身份等询问目标，选择对应疑问词与构式。疑问成分通常留在所询问成分的位置；兼表“怎么／为什么”的形式依完整语境确定读法。参考语法：[是非问与选择问](https://tujia.biz/#grammar/north/105?grammarAnchor=north-20-1)、[疑问词及其位置](https://tujia.biz/#grammar/north/105?grammarAnchor=north-20-2)。

## nie 与 niexi：显式中心词和独立指称

参见 [nie、niexi 与独立指称](nie-niexi.md)。用途物可按语境表达为“开瓶子的”一类名词化短语，按语境选择独立名词化或显式中心名词。Feng（2025）例27的独立指称 niexi 不能省 xi；带显式中心词的例27b可用 nie。领属表达、内置关系从句及其他动词短语的替换条件分别核查。
