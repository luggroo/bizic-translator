# 句型、否定、性质词与名词短语 / Clause and noun-phrase patterns

本文件处理句法与名词短语；体貌见[体貌与情态](aspect-modality.md)。 先从 [grammar-index.md](grammar-index.md) 路由；所有引例使用 **调号拼音＋IPA** 对齐。B06 为 Brassett 等（2006）；按所选方言组织词形。

<a id="basic-order"></a>
## 基本语序

北部的普通及物陈述使用主语—宾语—动词。Brassett 等（2006）75页例16为 /ŋa²⁴ li⁵¹ ka⁵¹/（我｜土｜挖），例17为 /a²⁴ta⁵⁵ ã⁵⁵ŋai⁵¹ xa²¹/（姐姐｜弟弟｜打）。这里保留参考语法所列 IPA，不另行转换拼写。新句可以替换有证据的同角色成分；否定、体貌、双宾语及话题化按各自构式处理。

南部同样以主语—宾语—动词为基本语序。《土家语三种句式的类型学特征》（2019）76页例27（泸溪且己）为 /ŋo³¹ ɲi³¹ doŋ²¹ dʑian²¹ ʕɯ¹³/（我｜你｜铜钱｜还），说明该例的间接宾语在直接宾语前。这个语序依据不使且己的代词音值自动适用于其他南部来源。

<a id="negation"></a>
## 1. 否定：事实、判断、意愿、禁止，分别选形

参考语法：[事实否定与意愿否定](https://tujia.biz/#grammar/north/104?grammarAnchor=north-21-101)、[系动词否定](https://tujia.biz/#grammar/north/104?grammarAnchor=north-copula-negation)、[禁止、停止与状态不再持续](https://tujia.biz/#grammar/north/104?grammarAnchor=north-21-103)。

- **事实否定 dá**：报告事件、状态或一般习惯；B06:132例167“我不喝酒”描述不喝酒这一事实。
- **意愿／判断否定 tā**：表达特定行动的选择、拒绝或说话者对事态的判断；B06:132例172用同一喝酒谓词表达选择不喝酒。否定的作用对象与动作阶段分别确定，情态见[意愿专题](aspect-modality.md#volition)。
- **禁止**（“别说”）：在特定记录里前置；带“现在就……”的即时禁止可用有例证的 `ta + V + gu`。完整句型、与 `do/bo/xie/lie` 的选择见[祈使与指令](directives.md#prohibition)。
- **不是**：名词谓语后用 sǒudá /sou²¹ta²⁴/ 或 búsī /pu²⁴sɨ⁵⁵/（B06:52，例17）。
- **双层否定**：“并不是不能住”之类可在带负义的情态之后另加事实否定，作用域须从整句判断。

<a id="nominalization"></a>
## 3. 性质词、名词化、量词

参考语法：[形容词与性质动词](https://tujia.biz/#grammar/north/104?grammarAnchor=north-6-2)。

- “冷、脏”等基本式可以作谓词；作定语时不能自动沿用基本式。部分派生性质词有固定长式（如“大、长、好”的不同形态）；性质词连接及关系化须核对中心名词是否出现。
- **北部性质词修饰的默认规则**：只有同一方言、同一词形有明确的**直接定语用例**（如已记录的长式形容词；也包括确有裸修饰例证的同形兼类词）时，才可采用不带连接成分的直接修饰。仅有词典释义“形容词／乱／黑”或性质谓语用例，**不能**证明可以直接修饰名词。没有这种证据时，显式中心名词默认用 **[性质词／性质谓词 + niě + N]**；有对应构式例证时也可用 **[性质词 + niěxi + N]**。独立指称（省略中心名词）另按 niexi 名物化条件选形；不要因为缺少长式就创造无连接的定语。
- Feng（2025）例27a–b的关系化／独立指称例句原文无调；引例保留无调记音，其转写来源见 [notation-audit.md](notation-audit.md)。
- 量词次序优先参考对应名词的语义类；**名词＋数词＋量词**同样适用于汉语名词插入。

<a id="property-decision"></a>
### 性质词与修饰语：先中心词，再分类和排列

以下为北部材料的决策顺序，南部须使用相应南部来源。

| 分析结果 | 词形与排列 | 核对重点 |
| --- | --- | --- |
| 性质陈述 | 主语名词短语＋性质谓词；常用基本式 | 结合完整词形、句法功能和来源例句判断；扩展式也有作谓语的例子 |
| 无显式中心词的“好的／长的” | 使用有依据的独立指称式或名物化结构 | 先确定所指，再按独立指称的例句选形 |
| 有证据的形容词直接修饰名词 | 中心名词＋**已记录可直接定语的形容词词形**；数量短语通常为 N＋Adj＋数＋量 | **仅在同方言同词形有直接定语用例时使用**；优先采用有证据的长式／派生式。里耶等有用例的同形兼类词是例外，不可推广到其他基本式 |
| 性质词加连接／名物化标记（**无裸修饰证据时默认**） | 显式中心名词前用 **性质词／性质谓词＋niě＋N**；同类例句支持时可用 **性质词＋niěxi＋N** | 先查是否存在可直接定语的完整长式；没有则不要输出裸形容词。niě、niěxi 的声调和适用范围按同来源构式核对；无中心名词时另按独立指称选择 |
| 带论元的关系从句 | 常见从句＋连接／名物化标记＋中心名词 | 查 [nie/niexi](nie-niexi.md)，保留主宾关系；标记选择有例句限制 |
| 名词修饰名词 | 通常修饰名词＋中心名词；有的结构用 niě | 按名词关系选择前置结构；niě、xi 的使用分别核对相应例句 |

### 顺序对照与来源锚点

- 有证据的直接形容词：`hàliě bíkuī ōng lǒng`“五只小狗”；`mùniě hxěbǎ sō zí`“三根长竹子”（B06:101、例66）。复用时保持中心名词在前、已证直接修饰词形在后，数量和量词接在整个名词—形容词组合之后。
- **反例与改法**：“杂乱的声音”写作 **`luán niě árē`** /luɛn²⁴ ɲie²¹ a²⁴zɤ⁵⁵/（disorderly LINK sound），不要写成 `árē luán`。
- 谓语与定语：`gědī cīpū hxě`“这本书长”（B06:107，例2）；`lò cái`“好人”（B06:101，例69）。谓语采用 hxě，直接修饰采用 hxěbǎ，分别匹配各自句法角色。
- 关系从句前置：“妈妈喂-nie(+xi)＋猫”（Feng 2025:6，例13）；名词修饰语前置：“木＋屋”（Feng 2025:4）。分别按事件论元结构和名词关系分析这两种前置修饰语。
- 有明确用例的同形兼类词：“红布”按“布＋miàjiě”组织，“这块布红”按“这块布＋miàjiě”组织；“新书／这本书新”同理使用 áxì。这里展示里耶调查词形及构式示意，**仅是这些来源和词形的已证例外**，不能据此推论所有性质词均可裸修饰。

上述补充依据本地参考语法 §4.2（`bizic-dictionary` commit `1079abec40bf8aa99af72faa6d13c10e3ef32d20`）；B06、Feng 与里耶调查分别保留来源范围。本次读取的是整理后的参考语法，不声称重新核过全部原著。

<a id="comparison"></a>
### 程度、评价与比较

区分性质的强度、对动作的评价和两项之间的比较；比较时明确比较基准、被比较项及差量。参考语法：[程度与评价](https://tujia.biz/#grammar/north/104?grammarAnchor=north-overview-degree)、[比谁更……、相差多少](https://tujia.biz/#grammar/north/104?grammarAnchor=north-23-2)。

<a id="addition"></a>
### 追加与焦点

追加另一项事件或数量时，采用与所指范围相符的追加成分。B06 的 bé /pɤ²⁴/（be²，rn455212“also”）位于其所追加的谓语前；139页例215的后半句 `guo² nie³ jie² be² die³ la¹ hu³` 表示“他的胳膊也开始要断了”。持续至某时的“还”见[持续与范围](aspect-modality.md#still)。

<a id="questions"></a>
### 疑问句

先确定是非问、选择问或成分问；成分问再区分价格、方式、原因、数量或身份等询问目标，选择对应疑问词与构式。疑问成分通常留在所询问成分的位置；兼表“怎么／为什么”的形式依完整语境确定读法。参考语法：[是非问与选择问](https://tujia.biz/#grammar/north/105?grammarAnchor=north-20-1)、[疑问词及其位置](https://tujia.biz/#grammar/north/105?grammarAnchor=north-20-2)。
