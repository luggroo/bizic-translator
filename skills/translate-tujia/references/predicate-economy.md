# 谓语组织

1. 分析事件、参与者、结果、时间与语气；移动事件确定路径和参照点。
2. 检索整词、固定搭配和近例，优先沿用语义关系最接近的完整谓语，保持其构式边界，按同义项与论元作替换。
3. 以原文的断言、时序和焦点为组句骨架，标出词汇及构式已承担的意义，为尚需表达的阶段、关系和范围选用成分。
4. 按动词及其作用范围分组，为各成分保留独立意义，以同来源整例或明确的生产性构式为依据，依[词缀顺序表](aspect-modality.md#particle-order)组句。
5. 写出有据的表层词形、声调和融合，逐项读回源义，将疑点定位到具体片段。

书写格式见[输出规范](output.md)。词汇入口见[动词索引](source-lexical-notes.md)，移动构式见[趋向](direction-suffixes.md)。
