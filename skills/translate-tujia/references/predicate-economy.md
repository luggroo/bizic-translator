# 谓语组织

1. 分析事件、参与者、结果、时间与语气；祈使／禁止／劝请优先按[指令构式](directives.md#choose)按主要指令意义选一个构式，`gu／do／bo／xie／lie` 执行时互斥；一般请求开始活动选 `gu`，这层意义可由语境隐含。移动事件确定路径和参照点，文献固定组合按整例使用。
2. 检索整词、固定搭配和近例，优先沿用语义关系最接近的完整谓语，保持其构式边界，按同义项与论元作替换。
3. 先确定名词修饰、从属关系和独立断言的结构层级，再以原文的断言、时序和焦点为组句骨架。属性留在名词短语中；独立事件按小句组织。逐个标出词汇及构式已承担的意义，再为尚需表达的阶段、关系和范围选用成分。结构对照见[事件组织](event-linking.md#lie-topic-chain)。
4. 按动词及其作用范围分组，为各成分保留独立意义，以同来源整例或明确的生产性构式为依据，依[词缀顺序表](aspect-modality.md#particle-order)组句。叙事句末表达已完成事件时，先选语义匹配的liao／bolu；lie有多种可读功能时优先采用更清楚的形式，先后步骤按对应构式选形。
5. 写出有据的表层词形与声调；仅在来源有词形证据时使用音变或合音，不以 gu 推导 liao、diu 等形式。逐项读回源义，将疑点定位到具体片段。

书写格式见[输出规范](output.md)。词汇入口见[动词索引](source-lexical-notes.md)，移动构式见[趋向](direction-suffixes.md)。
