# 整句对齐

对照原文、参考近例及来源支持的构式核验实际译文：核心谓语、参与者、动作与结果、路径与指向、阶段与极性、[词缀顺序与共现](aspect-modality.md#particle-order)、数量与范围、句间关系及语气。

译法选择见[谓语流程](predicate-economy.md)。评审将词汇依据、组合依据和实际译文逐项对应，标明疑字、配对、读音或适用范围的具体疑点。

逐个名词短语核对[中心词记录](translation-workflow.md#head-anchoring)：已证直接形容词用原例词形；普通性质词默认“性质词＋niě＋名词”，有对应实例时可用 niěxi；独立名物化另按所指选形。复查数词量词与修饰范围，发现顺序错误直接修正。词缀、格助词无固定调值时可不标调。
