# 整句对齐

对照原文、参考近例及来源支持的构式核验实际译文：核心谓语、参与者、动作与结果、路径与指向、阶段与极性、[词缀顺序与共现](aspect-modality.md#particle-order)、数量与范围、句间关系及语气。

译法选择见[谓语流程](predicate-economy.md)。评审将词汇依据、组合依据和实际译文逐项对应，标明疑字、配对、读音或适用范围的具体疑点。

逐个名词短语核对[中心词记录](translation-workflow.md#head-anchoring)：直接形容词是否在中心词后；前置修饰语是否确为相应名词修饰语或有依据的连接／关系结构；基本性质式、派生式及同形兼类词是否匹配实际句法角色；数词、量词和修饰范围是否正确。依据完整词形、句法功能和来源近例分类；-ba、-i、-kui 等词尾作为检索线索。发现顺序错误直接修正，再复核意义。
