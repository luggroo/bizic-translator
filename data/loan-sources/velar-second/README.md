全表从《广韵》25,336 条小韵字目中检出 1,573 条二等读音，涉及 1,379 个校正字头。查一个字时，先看它在《广韵》有几个读音，再看吉首、重庆的例词是否对应所查的意义。同一字头的方言记录出现在多个小韵行时，只算一组现代记录。[全表](screen.tsv) · [常查字](focus.tsv)

## 怎样读方言证据

「架」在书第 39 页有完整的一对白读与文读。白读 `ka5` 用于「十字架儿」，文读 `tɕia5` 用于「吵架」。汉字音典吉首点另收 `ka5`「白，葡萄架」，重庆点收 `tɕia5`，后者没有标注语体。像这样的同地书证可以补足单字调查表的空缺。[书页转录](../jishou-li-2002.tsv) · [吉首点](../jishou.tsv) · [重庆点](../chongqing.tsv)

| 字 | 吉首、重庆资料能说明什么 |
| --- | --- |
| 鞋、懈、跨、虹 | 这四字均在书页举例之外，吉首点逐条标了文、白。鞋为 `ɕiei2` 文、`xai2` 白。虹为 `xuŋ2` 文、`kaŋ5` 白。《广韵》虹另收匣母一等「戶公切」；二等条目只能证明该字另有见母江韵去声。 |
| 角、阶 | 吉首点「元角分」为 `tɕio2`，「牛角、角落」为 `ko2`。重庆点「階」兼收 `tɕiai1`、`kai1`。字表均未给这些读音标文白。 |
| 皆、瞎 | 「皆」吉首 `kai1`、重庆 `tɕiai1`，「瞎」吉首 `xa2`、重庆 `ɕia2`。这些记录说明两个地点读法有别，同一地点是否另有另一读仍待调查。 |
| 街、界、匣 | 「街」两点均录 `kai1`；「界」仅重庆表查到 `tɕiai5`；「匣」两点均录 `ɕia2`。这些字仍可按小韵或测点查到。 |

「间」的间隔义在《广韵》见母山韵用「閒」。「中閒」见古閑切（第 556 小韵，平声），「隔也」见古莧切（第 2685 小韵，去声），分别可对书中「中间、课间操」和「间开、间隔」。把「闲暇」的读音归到这两义会混入第三套用法。「咬一口」则应查疑母上声「齩」五巧切（第 1708 小韵，「齧也」）；《广韵》字头「咬」的两条平声分别释为「鳥聲」「淫聲」。[教育部《异体字字典》「閒」](https://dict.variants.moe.edu.tw/dictView.jsp?ID=48012&la=0) · [《重编国语辞典修订本》「齩」开放资料](https://www.moedict.tw/raw/%E9%BD%A9)

资料有异时可同时查两列。第 39 页「谏」注「咸开二见母」，《广韵》「諫」为見開二刪去，属山摄。第 40 页「虾」注「假开二晓母」，《广韵》「蝦」胡加切属匣母，古释「蝦蟆」。第 39 页「确实、确定」注溪母，与「確」苦角切相应；《广韵》另有「确」胡覺切，匣母，古释「磽确」。这两项同样可以由现代简体「确」查到。[常查字及对照](focus.tsv)

## 收录范围与字段

- 声母按原始音韵地位分列。牙音见 450、溪 205、羣 0、疑 117 条，喉音影 209、晓 175、匣 417、云 0 条。涉及假、梗、蟹、效、山、江、咸七摄。`rhyme_heading` 是原书分声调的韵目（如「禡」），`rhyme_class` 是跨调韵类（如「麻」）。江韵的部分原始音韵地位未列开合，表中留空。
- `head_source` 保留原数据的校订括号及合体描述，`head` 用校正后的字头做匹配。例如「膠〈𥉾〉」按「𥉾」查方言。1,380 个原字头写法经校订得 1,379 个字头，同字在不同小韵可以重复出现。「⿰隺犬」作为一个合体描述检索。
- 吉首表有 224 个校正字头能按同字、单一对应的简繁字或上述按义异体相连，重庆表有 275 个，两表共有 212 个。多指的简繁归并注明「简繁歧义线索」，不计入这三数。「确／確」等仍可逐条按书注声母、古义、用例判断。
- `book_pairs` 的左右列来自书中白读、文读；`book_comparison` 按页码、序号标出书注是否与这一行的声母、等第、摄及已知开合相符。多个小韵可能共享这些条件，书注没有给小韵号。地方调查行按字头展出，带测点、原注和行号；其读音只在词义、用例允许时才能对应某一个小韵。
- `review` 中「同点两组声形」指记录同时出现后部声母（如 k、ŋ、x）和舌面辅音或前高元音、介音起首；「跨点」指两组分别在不同地点。两项供定位待查例词，未带文白原注的读音不据此分层。重庆表没有明确的文白标记。
- 声旁栏的「說文」「MMH」分别指段注本所引《说文》正文和现代字形资料。传统「講」从冓声，简体「讲」的现代资料列井。659 个原字头至少有一种资料明确给出声旁，其余 721 个留空。省声、亦声以及不同来源的分析各有标记。[声旁来源、授权与重建方法](phonetic-components.md)
